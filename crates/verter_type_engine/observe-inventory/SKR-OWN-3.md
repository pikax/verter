# Lease-owned semantic graph lifetime inventory

Classification follows [the observation policy](../../../docs/arch/semantic-observe.md).
Counted ownership is the sole production lifetime authority of the semantic
graph: every live slot is owned by a counted child edge from a live parent, a
root (a node root set, a construction or dispatch scope, a delivery lease, a
cache candidate, a signature-epoch token, a union view, a refusal summary, an
inline flight) or is one of the twelve `Global` primitive vocabulary nodes. A
last release destroys the node iteratively, together with every child it alone
owned. There is no canonical payload sweep, no ordinal watermark, no activity
gate and no inactive or test-only reclamation mode. A document close evicts
only cache owners bound to the closed content; a held node is never revoked.

Nothing here records history: every row is ownership, a policy charge or a
current count, so nothing is gated on `semantic-observe`.

`release_canonical` and its live-slot scan, `GraphOwnership` and every
constructor parameter threading it, `CountedOwnershipHarness`, the counted
host constructor, `SemanticGraphStore::release_canonical` /
`release_canonical_payloads_below`, `released_any`, `result_is_live`,
`family_names_released_node`, `SemanticReleaseReport`, the session
`semantic_activity` module (`SemanticActivityGate`, `SemanticActivityGuard`,
`SemanticReclaimStats`, `SemanticReleaseReceipt`, the deferred-release queue
and its watermark), `GuardedHost` / `HostRef`, the LSP guarded-host module and
the `deferredReleases` / `releasesApplied` / `releaseWaitMaxMicros` /
`lastRelease` statistics.
