# Conditional continuation state

Classification follows [the observation policy](../../../docs/arch/semantic-observe.md).
The interface is described in [root continuations](../../../docs/arch/root-continuations.md).

| Item | Production consumer | Classification | Lifetime | Owner module | Gate |
| --- | --- | --- | --- | --- | --- |
| `ConditionalDecision.prepared`, `PreparedConditionalOperands` | The decision resumes selection from the operands already prepared; their adopted observations remain in the owning frame's taint and tracer | REQUIRED | One conditional frame, or one synchronous decision | `src/project_semantic_dispatch/conditional_decision.rs` | always |
| `ConditionalDecision.selection_started`, `ConditionalDecision.distribution`, `ConditionalDistribution` | The decision retains absorption/distribution classification and the completed member prefix, ordered results, self roots and positional completeness across dependency delivery | REQUIRED | One conditional frame, or one synchronous decision | `src/project_semantic_dispatch/conditional_decision.rs` | always |
| `ConditionalDistribution.normalization_members` | Prepare the final reduction's canonical member order once and retain its memo identity across dependency delivery | REQUIRED | One distribution | `src/project_semantic_dispatch/conditional_decision.rs` | always |
| `ConditionalDecision.selected`, `ConditionalSelection` | A completed relation/inference verdict, bindings and false-recovery classification survive a selected winner's dependency wait; adopted observations remain in the frame | REQUIRED | One conditional frame, or one synchronous decision | `src/project_semantic_dispatch/conditional_decision.rs` | always |
| `ConditionalDecision.ops`, `DecisionOp` | Retain each standing native operation's locals, cursor, completed prefix and held observation; deliveries resume under the same observation and abandonment releases inner accounting first | REQUIRED | One conditional frame or one synchronous decision | `src/project_semantic_dispatch/conditional_decision.rs` | always |
| `DecisionOperation::Fact`, `StructuralFactRead` held by a decision | A structural-fact demand or composite reduction the decision stands at keeps the evaluator's owned walk across its reads; abandonment releases it through `abandon_structural_fact_read` | REQUIRED | One standing decision operation | `src/project_semantic_dispatch/conditional_decision.rs` | always; allocated only when the demand names a read |
| `ConditionalOperandWalk` | Frame-only identity-carrier state and completed relation operand answers; one owned box transfers from the walk through preparation and selection, with no native decision allocation | REQUIRED | One conditional frame | `src/project_semantic_dispatch/conditional_decision.rs` | always; allocated only by the frame drive |
| `FamilyBuild::Conditional` | The ordinary family driver owns the same decision across child needs and thread transfer | REQUIRED | One conditional family build | `src/project_semantic_dispatch/family_continuation.rs` | always |
| `CONDITIONAL_READ_TRACE`, `trace_conditional_from_lowering_for_tests` | None; an explicitly installed test capture records only that active in-place driver's requested keys for comparison with manual stepping | OPTIONAL | One test capture on one thread; absent unless explicitly installed | `src/project_semantic_dispatch/conditional_decision.rs` | `cfg(any(test, feature = "test-support"))` |
| `OPERAND_PREPARATIONS`, `conditional_operand_preparations_for_tests` | None; tests count the actual preparation entry on each polling thread to detect replay | OPTIONAL | One test thread | `src/project_semantic_dispatch/conditional_decision.rs` | `cfg(any(test, feature = "test-support"))` |
| `DISTRIBUTED_MEMBERS`, `conditional_distributed_members_for_tests` | None; tests count completed member folds at the production fold to distinguish retained traversal state from repeated reads of memo answers | OPTIONAL | One test thread | `src/project_semantic_dispatch/conditional_decision.rs` | `cfg(any(test, feature = "test-support"))` |
| `BRANCH_SELECTIONS`, `conditional_branch_selections_for_tests` | None; tests count entries to the relation/inference selection stage and detect completed selections repeated during winner suspension, including replay shared by synchronous and polled entries | OPTIONAL | One test thread | `src/project_semantic_dispatch/conditional_decision.rs` | `cfg(any(test, feature = "test-support"))` |
| `SemanticTask::poll_read_for_tests` | None; tests compare the terminal read's completeness, diagnostics and receipt with the synchronous entry without requiring cache admission | OPTIONAL | Derived from one poll; no extra retained state | `src/project_semantic_dispatch/query_frames.rs` | `cfg(any(test, feature = "test-support"))` |

No production decision reads the optional counters. A default build contains
none of their storage, increments or readers. No production history or trace is
added. The optional test capture is absent from a default build.
