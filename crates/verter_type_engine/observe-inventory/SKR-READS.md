# Read-delivery inventory

Classification follows [the observation policy](../../../docs/arch/semantic-observe.md).

## verter_type_engine

| item (field, store, hook, counter, trace) | production consumer | classification | lifetime | owner module | gate |
| --- | --- | --- | --- | --- | --- |
| `DemandCostReceipt` (identity, exclusive `LogicalUsage` of work, bytes and request operations, prerequisite receipts and how each was consumed (`Nesting`)) | Every warm, joined or prefix read replays it through `ConnectedDemandLedger::replay_admit` before the result serves | REQUIRED-budget | Shared by the candidates, flights and consumer receipts that reference it; freed with the last | `src/project_semantic_dispatch/cost_receipt.rs` | always |
| `OperationFootprint` (query depth, instantiation height and drive requirement, tail-step peak) on each receipt; `CostScope::tail_steps` | `replay_admit` refuses a replay whose cold run the reader's query-depth, instantiation or tail allowance could not complete | REQUIRED-budget | The receipt / the open recording | `src/project_semantic_dispatch/cost_receipt.rs`, `connected_demand.rs` | always |
| `DemandCostReceipt::retention` (`RetentionCharge`) | The process retention account charges each retained receipt once, from the first store that retains it until the receipt drops | REQUIRED-lifetime | The receipt | `src/project_semantic_dispatch/cost_receipt.rs` | always |
| `MemoEntry::cost_receipt` | The family-memo warm reads (`get_validated_value_impl`, the fast path) hand it to the reader; backfilled prefixes and SCC members share the publishing build's | REQUIRED-budget | The candidate | `src/semantic_query_memo/family.rs` | always |
| `PublishedMemoCandidate::cost_receipt` | The SCC member batch publishes its members under the root's receipt | REQUIRED-budget | One publication | `src/semantic_query_memo/mod.rs` | always |
| `InflightState::cost_receipt` | A subscriber replays the producer's receipt as a warm read does | REQUIRED-budget | One flight | `src/semantic_query_memo/inflight.rs` | always |
| `CacheRead::receipt` (`ReadReceipt::Priced` / `Unpriced`) | Every read envelope carries its value's receipt: warm hits, joined flights, own builds and the modeless relation / flow-return / call-resolution and deferred-evaluation reads. The dispatch admits a priced read's receipt (`admit_served`) or computes the result itself, and the consuming frame records it as its prerequisite | REQUIRED | One read | `src/semantic_query.rs`, `src/project_semantic_dispatch/cost_receipt.rs` | always |
| `ClaimAttempt::recompute` | A claimant refused a stored result's receipt claims the key to compute it on a flight of its own, leaving the candidate in place; a subscriber woken on another producer's unpriced partial produces alone the same way | REQUIRED | One logical claim | `src/semantic_query_memo/producer.rs` | always |
| Cost-scope stack with repeat flags, and the demand's paid set | Charges accrue to the computation recording on top; a repeat of a paid computation is recorded, never charged | REQUIRED-budget | One connected demand | `src/project_semantic_dispatch/connected_demand.rs` | always |
| `RequestBudget` operations-paid set | Replays charge a computation's request operations once per request | REQUIRED-budget | One request | `src/request_budget.rs` | always |
| `ConnectedDemandLedger::request_effects` (operations spent, computations first paid) | A root's refusal is sealed only when the request moved by exactly these effects, and the summary keeps only them | REQUIRED-budget | One connected demand | `src/project_semantic_dispatch/connected_demand.rs` | always |
| `PrefixRecording` (a path walk's held pre-walk charges) | Each linear prefix a walk backfills is sealed with the receipt of the hops that reached it | REQUIRED-budget | One path walk | `src/project_semantic_dispatch/connected_demand.rs`, `walk.rs` | always |
| `BudgetProfile` intern table (weak entries) | The refusal identity of an isolated root, interned only to seal or look up a refusal | REQUIRED-budget | Process table holding only live profiles; an entry is removed when its last holder drops | `src/project_semantic_dispatch/cost_receipt.rs` | always |
| `RefusalSummaries` (refusal read, observed facts and self-roots, failed-prefix charges, trip) | An exact isolated-root repeat answers from it after revalidating the facts | REQUIRED-budget (summaries); REQUIRED-lifetime (the bounded table, its lock-free length, each summary's retention charge) | Bounded FIFO of `REFUSAL_SUMMARY_CAP` and by the process retention account (a declined summary is not sealed); cleared with the memo | `src/semantic_query_memo/refusal_summary.rs` | always |
| `ProjectSemanticDispatch::driven_root_traced` | The drive's entry seals its root's refusal on the facts the root frame traced | REQUIRED | One drive: set by the root frame's completion, taken by the entry | `src/project_semantic_dispatch/query_frames.rs` | always |
| `ProjectSemanticDispatch::published_results` (priced read, carrier, edit clocks) | A claim the memo cannot serve back to the dispatcher's view reads the result its own build published instead of recomputing it | REQUIRED-budget (the receipts); REQUIRED-lifetime (the table) | The dispatcher; an entry is tagged with the edit clocks sampled before its build ran (`InstantiateFrame::computed_at` for frames), so a result computed across an edit is never served | `src/project_semantic_dispatch/mod.rs` | always |
| Deferred-evaluation memo receipt (`evaluate_deferred_memo` value) | A hash-cons hit replays the evaluation's receipt before it serves | REQUIRED-budget | The memo entry (bounded FIFO, cleared with the memo); the receipt is charged to the retention account, and an entry the account declines is not kept | `src/semantic_query_memo/hash_cons_memos.rs` | always |

No optional counter, trace or charge-attribution history is added: receipts, sealed failed prefixes and their validity rails are required budget state, so nothing is gated behind `semantic-observe`.
