# Counted ownership substrate inventory

Classification follows [the observation policy](../../../docs/arch/semantic-observe.md).
Production canonical sweeps remain authoritative. The graph's last-root node
destruction is enabled only by the controlled test/test-support harness.

No detailed ownership allocation history, permanent profile history or delivered
version registry is introduced. Policy reservations continue to use the one
process retention account; no computation memory cap is added. Test fixture
carrier defaults, compile-fail expectations and the memo layout sentinel reflect
the transport interfaces, not separate production stores or telemetry.
