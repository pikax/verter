# Semantic allocation ownership and charge transfer inventory

Classification follows [the observation policy](../../../docs/arch/semantic-observe.md).
Every row below is a REQUIRED policy charge or a REQUIRED current count:
nothing here records allocation or attribution history, and nothing is
gated on `semantic-observe`. Policy reservations use the one process-local
retention account; no computation-memory cap is added — graph storage and
flights are `Pinned` (charged, never refused), and a refused cache
admission returns its complete value uncached.

## Declared conventions

| Convention | Rule | Owner |
| --- | --- | --- |
| Heap block | `n > 0` payload bytes cost `n` rounded up to 16 plus a 16-byte header; zero bytes allocate nothing (`heap_block_bytes`) | `verter_session_query/src/retention/allocation.rs` |
| Capacity | `String` / `Vec` cost their capacity, never their length | same |
| `Arc` block | an `Arc<T>` / `Arc<[T]>` / `Arc<str>` block holds its two counters beside the value (`arc_block_bytes`); an empty slice still costs its counters | same |
| Embedding | a field's inline bytes ride the block of the value embedding it; a value held directly in a container slot rides the container's slot convention | same |
| Container slot | one map / FIFO slot costs `ENTRY_OVERHEAD_BYTES` (fixed-size slot, so a fixed figure); variable records an entry keeps are charged on top | `retention/mod.rs` |
| Self-charged allocation | every result receipt and evidence page, a cost receipt, a pooled identity string, an interned identity record (intersection recipe, semantic context, order domain, relation / call key), a budget profile, a delivery owner and a graph node carry their own charge; a holder pays only the handle's inline bytes | `allocation.rs`, `facts/receipt.rs`, `intern_table.rs`, `cost_receipt.rs`, `delivery_lease.rs` |
| Sealed owning handle | a delivered allocation a caller can keep — a dependency rail, a walker-diagnostic list, a value's outermost allocation and its nested lists, and the owned strings they name — is an `Owned` cell that carries its charge beside its value: every owning clone shares that one charge, the charge is released in the step that frees the allocation, no accessor exposes the raw `Arc`, and a cache hold keeps the cell alive, so a charge is never revived after release. The cell's block is the cell's own `Arc` block (counters, charge slot, inline value); a slice or string value adds its boxed backing | `verter_session_query/src/retention/owned.rs` |
| Nested owned allocations | measuring a value for its charge offers each nested `Owned` handle instead of counting it: the nested cell is charged by itself, once however many parents share it; a parent pins every child when first charged, and a cache retaining the parent retains every child too, all or nothing | `retention/owned.rs` (`Owned::offer`, `AliasSet::collecting`) |
| Aliases within one charge | each distinct `Arc` allocation counts once per charge (`AliasSet`) | `allocation.rs` |
| Aliases across owners | an allocation independently charged owners share is charged once through `AliasCharges`, keyed by address; the charge co-owns the allocation | `retention/shared.rs` |
| Leaf text | a leaf `Arc<str>` a registered carrier or an owned cell still reaches raw (an identity string) is its own registered charge, held by every carrier or cell reaching it in that holder's class (cache or caller) and released with the last; registration measures with a collecting `AliasSet` | `allocation.rs`, `retention/shared.rs`, `retention/owned.rs` |
| Caller-first charge | a delivery charges the self-charged allocations it hands out to its caller the moment it is minted — pinned, never refused; a cache retaining them adopts the same charge refusably, and hands it back to the remaining handles when it lets go | `retention/owned.rs` (`Owned::pin` / `Owned::hold`), `semantic_query_memo/{retention,delivery_lease}.rs` |
| Arena shared heap | a graph payload's and scope's heap is charged with graph storage; every `Arc` it reaches is counted once arena-wide by owner count (payloads and enclosing shared allocations) | `semantic_query_memo/arena.rs`, `semantic_query/node_payload_footprint.rs` |
| Weak-held block | an interned dependency rail's cell block stays allocated while the interner's `Weak` lives, so the interner charges it for its entry's lifetime; the rail's own charge covers its entry backing only (`Owned::new_with_block_charged_elsewhere`), and its canonicals are owned strings charged by themselves | `semantic_query_memo/interner.rs` |
| Process statics | the process-wide empty diagnostic list and dependency rail are static storage, never charged | `semantic_query_memo/mod.rs` |
| Granular storage pin | graph storage is charged in whole granules: never below the live total, above it by less than two granules, released entirely when the storage is | `retention/granular.rs` |
| Publication slot bound | a memo candidate pays for every slot its publication may populate (the slot plus each sibling a recorded point satisfies) | `semantic_query_memo/family.rs` |

## Open owners

These owners are not yet charged exactly; each is an unaddressed item of
this task, not optimization debt:

- identity strings and identity / key structures embedded in delivered
  values and diagnostics — `DeclIdentity`, `PropertyKey` / `IndexKey`,
  `QueryError` names, the `verter_type_expr` value identities and locator
  anchors, `FlowReturnKey` / `ResolvedDeclSlotIdentity` /
  `CanonicalTypeSubstitution` inside flow-return and call results, an
  object-projection alternative's fact / index / signature lists — are
  still raw `Arc` allocations. While an owned cell reaches one, the cell
  holds its registered leaf charge; an owning clone taken out of such an
  identity outlives that charge. The identity pool hands out the same raw
  `Arc<str>`. Ownership of the identity-string conversion is the open
  question `skr-own-account-identity-strings`;
- builder copies (`copy_in_scope`) allocate no backing of their own — every
  allocation they reach is an arena payload's or an identity string's — so
  they inherit the item above;
- a released graph payload a holder still keeps through an `Arc` is
  uncharged from its slot's release (the arena's payload heap is the same
  identity / payload class);
- a family key's names are measured with a non-collecting `AliasSet`, so a
  name the key shares with a registered leaf is counted in both;
- the origin-edge store's own tables and edge lists, and the shape cache's
  entries, carry no charge of their own; a delivered allocation they keep
  stays charged by its own cell (retained for an origin edge's fence,
  pinned for a shape-cache entry's rail).
