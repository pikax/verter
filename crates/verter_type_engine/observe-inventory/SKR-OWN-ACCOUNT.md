# Semantic allocation ownership and charge transfer inventory

Classification follows [the observation policy](../../../docs/arch/semantic-observe.md).
Every row below is a REQUIRED policy charge or a REQUIRED current count:
nothing here records allocation or attribution history, and nothing is
gated on `semantic-observe`. Policy reservations use the one process-local
retention account; no computation-memory cap is added — graph storage and
flights are `Pinned` (charged, never refused), and a refused cache
admission returns its complete value uncached.

## Declared conventions

| Convention | Rule | Owner |
| --- | --- | --- |
| Heap block | `n > 0` payload bytes cost `n` rounded up to 16 plus a 16-byte header; zero bytes allocate nothing (`heap_block_bytes`) | `verter_retention/src/allocation.rs` (re-exported as `verter_session_query::retention`) |
| Capacity | `String` / `Vec` cost their capacity, never their length | same |
| `Arc` block | an `Arc<T>` / `Arc<[T]>` / `Arc<str>` block holds its two counters beside the value (`arc_block_bytes`); an empty slice still costs its counters | same |
| Embedding | a field's inline bytes ride the block of the value embedding it; a value held directly in a container slot rides the container's slot convention | same |
| Container slot | one map / FIFO slot costs `ENTRY_OVERHEAD_BYTES` (fixed-size slot, so a fixed figure); variable records an entry keeps are charged on top | `verter_retention/src/lib.rs` |
| Self-charged allocation | every result receipt and evidence page, a cost receipt, a pooled identity string, an interned identity record (intersection recipe, semantic context, order domain, relation / call key), a budget profile, a delivery owner and a graph node carry their own charge; a holder pays only the handle's inline bytes | `allocation.rs`, `facts/receipt.rs`, `intern_table.rs`, `cost_receipt.rs`, `delivery_lease.rs` |
| Sealed owning handle | a delivered allocation a caller can keep — a dependency rail, a walker-diagnostic list, a value's outermost allocation and its nested lists, every identity string (declaration, slot, scope, locator-anchor, function, root and property identities, error names, budget contexts) and the owned strings and lists they name — is an `Owned` cell that carries its charge beside its value: every owning clone shares that one charge, the charge is released in the step that frees the allocation, no accessor exposes the raw `Arc`, and a cache hold keeps the cell alive, so a charge is never revived after release. The cell's block is the cell's own `Arc` block (counters, charge slot, inline value); a slice or string value adds its boxed backing | `verter_retention/src/owned.rs` |
| Nested owned allocations | measuring a value for its charge offers each nested `Owned` handle instead of counting it: the nested cell is charged by itself, once however many parents share it; a parent pins every child when first charged, and a cache retaining the parent retains every child too, all or nothing | `verter_retention/src/owned.rs` (`Owned::offer`, `AliasSet::collecting`) |
| Aliases within one charge | each distinct `Arc` allocation counts once per charge (`AliasSet`) | `allocation.rs` |
| Aliases across owners | an allocation independently charged owners share is charged once through `AliasCharges`, keyed by address; the charge co-owns the allocation. A raw list a family key shares with an arena payload (a template literal's quasis) is counted by each while both live: an over-estimate, never a gap | `verter_retention/src/shared.rs` |
| Owned below the DTO | `Owned` / `OwnedSlice` / `OwnedStr` live in `verter_retention`, below both `verter_type_expr` and `verter_session_query`, so identity types carry the handle end to end; an empty `OwnedSlice` allocates nothing and holds nothing | `verter_retention/src/owned.rs` |
| Debug invariants | in a debug build an owned cell's value reaching a raw `Arc` panics (`AliasSet::for_cell`), a measurement that drops collected handles panics (`AliasSet` drop), and a delivered carrier whose measurement counts heap outside its handles panics (`OwnedHandles::of`) | `verter_retention/src/{allocation,owned}.rs` |
| Footprint | a retaining owner's measurement returns `Footprint { bytes, handles }`: the bytes it charges itself and the owned allocations it reaches, which it pins (caller) or holds (cache) so each is charged by its own cell | `verter_retention/src/lib.rs` |
| Leaf text | a leaf `Arc<str>` a registered carrier still reaches raw (a fact's canonical, a self-root) is its own registered charge, held by every carrier or cell reaching it in that holder's class (cache or caller) and released with the last; registration measures with a collecting `AliasSet` | `allocation.rs`, `verter_retention/src/shared.rs`, `verter_retention/src/owned.rs` |
| Caller-first charge | a delivery charges the self-charged allocations it hands out to its caller the moment it is minted — pinned, never refused; a cache retaining them adopts the same charge refusably, and hands it back to the remaining handles when it lets go | `verter_retention/src/owned.rs` (`Owned::pin` / `Owned::hold`), `semantic_query_memo/{retention,delivery_lease}.rs` |
| Arena shared heap | a graph payload's and scope's heap is charged with graph storage; every raw `Arc` it keeps behind a borrow (payload arrays, a carrier's private name and arguments, a surface's private lists) is counted once arena-wide by owner count (payloads and enclosing shared allocations); every allocation a borrower can clone out (names, quasi lists, pending substitution frames) is an owned handle, pinned by the arena and charged by its own cell, shared with every other holder — there is no payload measurement of a bare `Arc`, so a public raw `Arc` field does not compile; a released slot whose payload a reader still holds hands the payload's block, heap and shared-allocation ownership to the payload itself, and the drop of its last holder gives them back in the same step | `semantic_query_memo/arena.rs`, `semantic_query/node_payload_footprint.rs` |
| Data tree | a retained plain data tree (a type expression, a flow slice or graph, a compile product, a declaration record) is measured exhaustively by `HeapSize`: every field of every variant, `String` / `Vec` / map by capacity, each distinct raw `Arc` once per measurement, owned handles offered to their own cells; `#[derive(HeapSize)]` measures every field, an `inline` field must be `Copy`, and a recursive tree (`#[heap_size(iterative)]`) is measured from a work-list, never the call stack | `verter_retention/src/heap_size.rs`, `verter_retention_derive` |
| Data-tree cell | a data tree a cache hands to its readers is one owned cell (`OwnedTree`): the cell charges the whole tree, every reader's clone shares that charge, and it passes to the readers when the cache lets go | `verter_retention/src/heap_size.rs` (`Tree`, `owned_tree`) |
| Hash table | a map or set costs one block of buckets sized to its capacity (a power of two at load at most seven eighths, at least four) plus one control byte per bucket and a probe group | `heap_size::hash_table_bytes` |
| Weak-held block | an interned dependency rail's cell block stays allocated while the interner's `Weak` lives, so the interner charges it for its entry's lifetime; the rail's own charge covers its entry backing only (`Owned::new_with_block_charged_elsewhere`), and its canonicals are owned strings charged by themselves | `semantic_query_memo/interner.rs` |
| Process statics | the process-wide empty diagnostic list and dependency rail are static storage, never charged | `semantic_query_memo/mod.rs` |
| Granular storage pin | graph storage is charged in whole granules: never below the live total, above it by less than two granules, released entirely when the storage is | `verter_retention/src/granular.rs` |
| Publication slot bound | a memo candidate pays for every slot its publication may populate (the slot plus each sibling a recorded point satisfies) | `semantic_query_memo/family.rs` |

## Open owners

These owners are not yet charged exactly; each is an unaddressed item of
this task, not optimization debt:

- the fact-validated and query-identity caches that keep their values as
  raw `Arc` candidates — `ValidatedFactCache` (routes, module exports,
  resolved import facts, fallthrough, imported roots) and the
  reverse-indexed candidate stores (the imported registry and its peers) —
  charge the evidence pages their signatures reach, but a candidate's own
  allocations and its value carry no charge of their own. Their values
  reach fact signatures and receipts that already charge themselves, so
  measuring them needs a fact-aware measurement rather than a derived one;
- a data tree's inner raw `Arc`s: a reader that clones an inner list or
  subtree out of a delivered artifact value (a type-expression subtree after
  the vault's authorized unwrap, a flow slice's or graph's lists, a compile
  product's code text, which public responses also hand out) aliases it
  without the cell's charge once the cell drops. Its scope is the question
  `skr-own-account-artifact-value-dto-aliases`.
