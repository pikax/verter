# Determinism matrix status — Verter Semantic Signature Kernel

The §5.9 mandatory determinism matrix of
[`docs/arch/signature-kernel.md`](../../arch/signature-kernel.md), as it is
actually driven by the tree.

**Registration is executable, not prose.** The row table lives in
`crates/verter_session/tests/cases/g_block/semantic_determinism_matrix.rs` and
is enumerated against the contract's own §5.9 table by
`determinism_matrix_enumerates_every_5_9_row`: a perturbation that is lost,
invented, renamed, or left without a driver fails there. This document is a
reader's index over that registration; it is never the authority, and it
records no run counts, timings or machine-bound numbers — those belong to a
run report, not to the tracked tree.

## Comparison bases

Every replay driver compares on **two independent bases**, so a
schedule-dependent answer cannot hide behind an unstable print, nor behind an
observation that stays fixed while the generated bytes drift:

1. **Completed observation** — the semantic-graph projection rendered to stable
   text (kinds, names, literal values, structural order). Never node ids,
   pointers or allocation ordinals.
2. **Generated-bytes digest** — the implementation's own content digests over
   the artifacts it generated from the upserted sources.

## The two ignored rows

An ignored row is **not** an empty body. Each asserts the known state — the
drivable subset, or the typed refusal that keeps the row undrivable — so the
change that un-ignores it inherits a real body rather than a stub, and the
registration assertion requires the reason to name the **missing public
surface** rather than a coordination identifier.

| Row | What must exist before it can claim Ready |
|---|---|
| DET-05 | A request-cancellation drive the caller controls: the audited flow-return entry mints and installs its OWN request context, so a caller cannot cancel the request it drives. And a persisted semantic cache: the product persists none across a process — backend/process identity and restart admission belong to the kernel-expansion cache-identity block, which owns "process restart … and cancellation reject stale admission". The public epoch rebuild (`clear_compile_cache`) is driven in the body. |
| DET-09 | An observation that depends on the semantic policy. The flow-return lane publishes the same answer under every `strictNullChecks` setting — an optional parameter is `string \| undefined` whether it is on or off, where TypeScript 7.0.2 prints `string` when it is off (ledger `SDL-13`) — so a resident parent answering from the old policy cannot be told apart from a correct one. The body pins that known state: its "answers do not move" assertion fails the day the lane honours the policy, which is the un-ignore signal. |

DET-08 was registered ignored on the claim that no narrower-than-whole-return
demand point is answerable. The evaluator models one — the member projection
behind `ReturnType<typeof f>["a"]` — and the row now replays it; the claim
generalised from the one point (`Demand::shallow()`) that genuinely is not
modeled, which the driver keeps pinned to its typed refusal.

## §5.4 stable-key table

The same file carries the §5.4 stable-key registration. It is enumerated
against the **live** `SemanticNodeData` declaration by
`stable_key_table_enumerates_every_semantic_node_data_category`: a new variant
cannot land without a registration row in the same change.

Every variant now has a `VerterStableV1` encoding. Four rows carry a
`residual` — an identity input the encoder **approximates** rather than
consumes, so the row's identity claim is weaker than its `inputs` column reads:

| Variant | Residual |
|---|---|
| `DeferredCallable` | The encoder walks the carrier type arguments only; the deferred subject reference is not an encoding input. |
| `ImportType` | The encoder consumes the authored specifier text, not a resolved module logical identity. |
| `RawFallback` | The encoder serialises the opaque payload's `Debug` form rather than a stable reference to the failed input. |
| `SyntheticBinding` | The encoder serialises the content-free binding id's `Debug` form; the synthesizing operation's owner/role anchor is not an encoding input. |

## Class 3 admission

An order-induced difference (§5.8 class 3) is admitted to
[`semantic-difference-ledger.md`](semantic-difference-ledger.md) only with the
contract's counterfactual: only semantic union traversal order changed, in an
isolated cache namespace (parents included), and restoring the stable order
recovers the recorded observation. No class-3 row exists.

Serialising node allocation to make a replay agree is forbidden by §12 and is
not how any row above is satisfied.
