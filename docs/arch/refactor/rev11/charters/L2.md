# L2 — Final equivalent-work performance decision

**Status:** LOCKED — contains binding acceptance criteria from the ratified timing directive; this charter is not separately authorized or dispatched. See the [landed timing ruling](../rulings/ARCHITECT-RULING-2026-08-23-TIMING-ARCHITECTURE.md).  
**Class:** Foundational.  
**Predecessors:** `B6`, `C4`, `D8`, `E4`, `H3`, `J4`, `K3`, `L1`.

## Objective

Make the final performance decision from equivalent correct work and latency/work distributions, never from a single threshold or a fast stale answer.

## Acceptance criteria

- Report distributions, including p50/p95/p99 where the locked cell requires them, rather than one hard latency threshold.
- Distinguish first response, first non-empty response, first correct response, convergence, work started, work superseded, work published, and work discarded.
- Pair every response milestone with an exact content/correctness predicate and the document/project/provider/dependency basis that was measured.
- Preserve the locked absolute SLO, self-no-regression, work/copy/allocation, boundary, competitor/Pareto, and bounded-memory decisions.
- A fast stale response is recorded as discarded/incorrect and never credited as latency success.
- Gate-performance work remains an independently measured landing unit. Runtime timing work receives no gate-speed credit without controlled before/after evidence, and correctness does not depend on the gate-performance experiment.

## Proof

Run warmups and repeated controlled cells with commit-pinned candidates. Publish distributions plus work attribution, timeout/retry/flake rate, and correctness predicates. First response and convergence are separate series; non-empty and correct are separate milestones.
