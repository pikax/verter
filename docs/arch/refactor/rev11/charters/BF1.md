# BF1 — Framework compiler contract and compatibility lock

**Status:** PROPOSED / LOCKED pending AMD-005 ratification. B1 is accepted.
**Class:** Foundational gate. **Predecessor:** B1.

## Objective

Convert AMD-005's package into a final, immutable execution lock before any harness,
safety retraction, or framework correction candidate exists.

## Owned scope

- exact Vue RC.3 and Svelte 5.56.8 source/package closures and integrity;
- product-boundary glossary and framework-owned architecture;
- product/route inventory and maturity/capability matrix;
- complete Vue and Svelte semantics-affecting option classifications;
- conformance acceptance IDs, official-case manifests, golden/normalizer contracts;
- fragment/assembly, SSR/hydration, and TypeScript-product contracts;
- emitter/mapping dispositions and BF3 probe inventory;
- exact performance cells locked before successor implementation; and
- final DAG, charter, capability, ledger, and gate amendments.

BF1 must resolve every `VERIFY`, `blocked`, and provisional option/capability row in
the lock itself or explicitly make the cell unsupported fail-closed. It does not
implement broad compiler behavior, the harness, or safety guards.

## Required evidence and exits

1. `FC-DOMAIN-001`, `FC-BOUNDARY-001`, `FC-OPTIONS-001`, and
   `FC-CAPABILITY-001` pass against immutable digests.
2. Package installs reproduce the committed package locks offline and reject drift.
3. Every official case seed has one allowed disposition owner and no case is absent.
4. Every reachable/default route is mapped to a capability cell and unknown semantic
   options fail construction by contract.
5. Each current emitter/mapping owner has exactly one disposition.
6. Performance cells, correctness oracles, repetitions, thresholds, counters, memory
   ceilings, fixture digests, and machine-lease policy are frozen before BF2 work.
7. The 56-row template and live-shape DAG validations pass and new rows remain locked.

## Abort/rescope

Stop for an unresolved immutable package, an unclassified semantic option, a missing
public/default route, an unmanifested official suite, an ambiguous product owner, a
performance criterion selected after candidate measurement, or pressure to place
framework behavior in B1.
