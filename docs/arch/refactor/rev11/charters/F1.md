# F1 — One committed input and coherent snapshot authority

**Status:** LOCKED — contains binding acceptance criteria from the ratified timing directive; this charter is not separately authorized or dispatched. See the [landed timing ruling](../rulings/ARCHITECT-RULING-2026-08-23-TIMING-ARCHITECTURE.md).  
**Class:** Foundational.  
**Predecessors:** `A6`, `B6`, `C4`, `D2`.

## Objective

Converge committed sources, overlays, project topology, and configuration into one coherently captured authority, with exact typed revision dimensions for later facts and flights.

## Acceptance criteria

- One immutable capture provides the exact document revision, relevant source-root/project revision, and configuration/resolver epoch.
- The capture contract has typed seams for a producer-owned provider/program-applied generation and a dependency read-set/stamp; F1 does not infer either from elapsed time or global idleness.
- `EngineRevision` orders commits and captures snapshots only. It is not a universal invalidation value, cache key, readiness receipt, or substitute for any exact dimension.
- An unrelated edit does not change an unrelated fact's basis and does not invalidate that fact.
- Ordered document mutation, coherent before/after snapshots, short write critical sections, and parse/compile/provider work outside the write critical section remain mandatory.

## Proof

Discriminating capture tests cross document, project/source-root, configuration/resolver, and unrelated-edit changes. Each test proves the affected dimension advances and unaffected dimensions remain reusable. A global-generation-only implementation fails this charter.

## Non-scope

F1 does not implement provider readiness, a generic flight system, a global clock, or a universal workspace-generation cache key. F2 composes exact observation bases; H2 mints provider-applied receipts.
