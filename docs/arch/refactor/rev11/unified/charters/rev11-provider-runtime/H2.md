The final and sole owner is **project-scoped ProviderHub with exact epochs, deadlines, and applied receipts**. This charter accepts one authority/migration/cutover boundary; it contains no independently dispatchable subblocks.

- Production surfaces: `crates/verter_lsp/src`, `crates/verter_type_runtime/src/tsserver`, and `crates/verter_tsgo_api/src/actor`.
