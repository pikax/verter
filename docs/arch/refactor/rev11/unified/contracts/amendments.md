# Amendment contract

An amendment is immutable, maintainer-ratified authority that changes static DAG/charter/catalog bytes and carries before/after digests plus mechanically computed descendant impact closure. Accepted history remains immutable. A false premise stops dispatch; the architect gives neutral options and seeks the best long-term architecture without cost/breaking-change bias. No agent or finding can self-authorize new critical-path scope.
