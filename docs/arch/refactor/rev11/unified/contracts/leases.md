# Ephemeral lease contract

Leases are runtime files outside authority. One repo-global trusted-local lock and anchor coordinate every registered runtime root, so the same node or conflict domain cannot be admitted twice through different roots and round ordinals are globally monotonic. Admission binds the node, holder, candidate start SHA/tree/ref/worktree, computed effort policy, and ready task briefs. It validates the complete packet before lease publication, then journals exact intended bytes; retry recovers exactly the committed marker. The anchor is mutable local coordination state, not an anti-rollback trust root.

Every public mutation performs a read-only preflight before acquiring the global lock and recomputes under that lock before writing. Renewal inherits every lease component exactly except its new identity/status link. `FIX_REQUIRED`, `ABORTED`, and `RELEASED` explicitly close a round. Only the current active round may accept. Local anchor loss blocks mutation until explicit operator reinitialization creates a new visible lineage with continuity `unknown/lost`.
