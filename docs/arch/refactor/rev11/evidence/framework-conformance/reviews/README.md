# Independent AMD-005 challenge dispatches

The package preparer intentionally did not author or self-satisfy these reports.
Three separate agents must create exactly:

- `architecture-challenge.md`
- `conformance-challenge.md`
- `governance-challenge.md`

Each report begins with the same exact candidate commit, repository tree, AMD-005
SHA-256, DAG SHA-256, Vue/Svelte package-lock and exact-closure SHA-256 values, and
both official-case manifest SHA-256 values. A changed identity invalidates all three
reports.

## Architecture challenger

Inspect framework separation, product ownership, B2/B3/B4/B5/B6/C3/C4 boundaries,
typed project demands, atomic publication, source spaces, every emitter disposition,
absence of universal semantic/runtime/options/fact architecture, and all retained DAG
edges. Challenge whether any proposed `Defer` evades an owner.

## Conformance challenger

Independently verify upstream tags/commits/trees, direct and transitive packages and
integrities, option completeness/classification, capability cells, official-case
enumeration, oracle/exclusion rules, normalizer discrimination, execution/link/map/
diagnostic/TypeScript/hydration requirements, and pre-candidate performance cells.

## Governance challenger

Inspect non-ratified status, preservation of B1's accepted identity and removed
worktree reality, state/DAG validity, predecessor exposure, concurrency and machine
leases, absence of production changes, scope completeness, review independence,
exact ratification action, and whether the candidate improperly claims acceptance or
rewrites accepted history.

Reports return `PASS` or `BLOCKING` with evidence. An agent that edits the package
cannot approve the edited tree; fixes require fresh independent reports.
