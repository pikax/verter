# B2 — Framework parsing, recovery, diagnostics, and stable identities

**Status:** PROPOSED amendment / LOCKED. **Predecessor:** BF3.

B2 owns the separate Vue and Svelte syntax frontends: parsing, recovery, syntax
diagnostics, syntax rejection, stable parsed identities, and only the syntax facts
needed by later framework semantic owners. It may share neutral text/span mechanics,
not a universal framework AST or semantic hierarchy.

B2 does not own framework code generation, normalized compiler options, product
planning, atomic publication, framework runtime semantics, or conformance corrections.
Its parsed identities must preserve exact source-space and framework/domain identity
for B4 mapping composition.

Exit requires official syntax/error cases assigned to B2 to have no blocked **B2
parse facet** in a supported parse capability, recovery diagnostics to be
deterministic and mapped, and syntax rejection to be typed and non-publishing. A
jointly-owned row's single aggregate disposition leaves `blocked` only once every
applicable facet has been closed by its owner; B2 closes and evidences its parse
facet and defers the remainder to the row's named co-owner. B2 and B3 overlap only with a
reviewed disjoint writable-ownership proof.
