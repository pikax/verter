## Scope results without additional blockers

- **Framework separation:** The B2, B3, BV1, BS1, boundary, and SSR contracts otherwise
  prohibit a universal Vue/Svelte AST, semantic hierarchy, runtime IR, options bag,
  fact bag, Vue-based Svelte lowering, and generated-product reparsing. No contrary
  universal framework architecture was found. The C3 object/defaults leak above is the
  identified exception to otherwise separate semantic ownership.
- **B2–B6 and C3–C4 boundaries:** B2 remains syntax-only; B3 owns request/default/
  prerequisite planning; B4 owns units/maps/publication; B5 and B6 own direct and
  prepared/batch routing without semantic repair; and C4 is proof-only. The blocking
  defect is the C3 protocol's admission of source-local object/defaults work, not a
  broad collapse of the other block boundaries.
- **Atomic publication and source spaces:** `fragment-assembly.md` correctly makes an
  IDE/provider companion's `SourceProjectionMap` a non-optional implicit product part,
  distinguishes optional runtime/build map data, preserves explicit source spaces, and
  requires all-or-nothing publication. The remaining blocker is that B4 cannot execute
  a complete cutover while current emitter/mapping owners are absent from its ledger.
- **DAG preservation:** A mechanical predecessor-list comparison found 51 base blocks
  and 56 candidate blocks. Exactly `BF1`, `BF2`, `BF3`, `BV1`, and `BS1` were added.
  Among original blocks, only B2, B3, B5, and C4 predecessor lists changed; every other
  original predecessor list is byte-identical. C1 retains `A6`, `B1`, and `B2`; C2
  retains `B3`, `B5`, and `C1`; all unaffected D–L edges are preserved.
- **Runtime boundary:** The reviewed amendment/charters/contracts define
  `RuntimeClient` and `RuntimeServer` as generated JavaScript for official runtimes,
  prohibit production official-compiler/runtime dependencies and fallbacks, and forbid
  Verter runtime implementation. The candidate tip commit changes documentation and
  evidence only; no hidden Vue or Svelte runtime implementation was introduced.
