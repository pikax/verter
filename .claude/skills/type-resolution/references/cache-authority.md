## Project-Global Cache Authority (post-rewrite)

`VerterHost` owns one `ProjectTypeStore` accessed via `.project_type_store()`. The store holds:

- `FileArtifactStore` — single canonical post-parse artifact per `(canonical_id, whole_hash)` (former `ModuleFactsDb` retired).
- `AnalysisReadyDb` — scope-parameterised analysis augmentation with bitflag-based satisfaction (`find_satisfying`).
- `RouteDb` — rehomed barrel/route surface cache, validated against live host facts.
- `OwnerImportSurfaceDb` — direct-owner-imports cache keyed by `(owner_canonical, owner_whole_hash)`. `VerterHost::owner_import_surface(...)` builds-or-fetches the surface; `resolve_owner_direct_import(owner, local_name)` is the single-call lookup every direct-owner-import caller uses.
- `FlowSliceStores` (`.flow_slice()`) — the flow-return substrate's per-function artifact stores: the shared `FunctionFlowGraphStore` graph memo, the retained-snapshot skeleton source, and the two content-addressed cache nodes over them (`FlowSliceHashNode` → `FlowSliceLoweredBodyNode`).
- `project_semantic_dispatch/flow_products.rs` owns selected product storage and exhaustive transfers/joins. `FlowProductExecution` binds immutable compact metadata to the content-pinned graph and sealed demand basis; its snapshots share that scope. The control interpreter supplies explicit executed transfers and source-ordered actual predecessor states. Dependency edges are selection authority, never control-flow predecessors. Bundle related writes and narrowing kills transactionally; unchanged successful work still records exact domain/declaration evidence. Reaching definitions carry selected execution scope. Widening joins use canonical algebra inspection and literal-value identity with pinned occurrences winning. Iteration limits count actual fixed-point rounds; acyclic execution does not fabricate rounds. `FlowExecutionSelection` owns validated structural execution independently of proof expansion; a `FlowDemandPlan` wraps the same Arc and only that exact plan can mint product evidence. Cap-only completion preserves cold values and cannot discharge obligations. Public selected sites and keys retain scope; raw addresses enter only through the interpreter's exact `BoundFlowGraph` attachment. Continuation snapshots use a persistent ordered map, so clones share structure and iteration visits active cells in domain/subject order. Exact source-declaration cells live in an append-only execution authority bank, surviving branch and lexical-scope restores; runtime aliases share only runtime-changing domains. `max_products` bounds runtime cells per continuation and `max_declared_products` separately bounds source facts over the execution lifetime. Execution handles are thread-local (`Rc`, compile-time !Send/!Sync); immutable graph and selection artifacts remain shareable `Arc` values. Publication has no callbacks, suspension, or evaluator reentry. Multiway joins merge ordered materialized streams with one queued head per predecessor, preserving source order without scanning absent cells; each domain accounts for missing paths through its bottom rule. Actual multiway reaching-type joins use one ordered contributor union and one bounded canonical provenance batch; they do not reset inspection budgets per binary prefix. Canonical union subsumption collects base-primitive presence once before filtering literal arms. Normalize narrowing aliases before measuring stored width. A successful transfer credits its exact key alone, never an unrelated execution site.

- Stable flow bindings live in `analysis/flow/binding.rs`: `FlowBindingMap` validates the exact identifier-span/kind correspondence to the full `FunctionProgramIndex` declaration inventory. Every value declaration has a real unique slot; type-only declarations have no value identity. `identity` preserves declaration evidence, while `canonical_local` and `runtime_identity` represent hoisted redeclarations of one runtime variable (parameters supply its canonical entry slot). `FlowBindingRef` carries a local skeleton ID or an exact captured identity; display names do not enter identity equality or hashing. The index owns every supported nested callable through one `NestedCallable` source-order discovery walk and lexical-parent key, including returned arrows and object methods. The index retains exact read identities and static paths, write-target identities, syntactic call/control-input roles, and transitive descendant capture facts. An ordered lexical-scope interval index resolves through per-scope name tables, visiting only containing ancestors instead of scanning same-name sibling declarations; parameter defaults retain their separate environment from body declarations, while runtime parameter/var aliases stay canonical. `build_indexed_function_body_skeleton` consumes those facts in one current-frame walk and returns the skeleton and exact binding map together; it never builds child skeletons to discover captures. Prepared reads, writes, callee roots, runtime binding aliases, and closure capture subjects carry exact `FlowBindingRef` values. Whole-identifier local declarations retain an optional annotation `FrameSpan`, giving both positive authority and a known negative without lowering; destructured locals retain their explicit typed boundary and parameters use signature authority. Nested values retain their exact indexed function and lexical context as deferred descriptors. A demanded child obtains its own retained graph and selection before lease-only content lowering; declared-return requests lower only its signature. Neither child bodies nor binding maps are rebuilt per demand. Product storage and graph admission remain shared session responsibilities.
- `SemanticGraphStore` — host-owned memo table + node arena for the `SemanticQueryKey` / `ProjectSemanticDispatch` layer. Every `SemanticQueryKey` variant dispatches through `ProjectSemanticDispatch::execute`; semantic subqueries dedup through the store's one memo protocol (`semantic_query_memo/producer.rs`): a validated lookup, then a claim that answers with the recursion sentinel, subscribes to another task's producer, or hands the claiming task the key's producer, which settles, is admitted (retention) and completes (delivery) as separate operations — the memo never runs a producer itself. A producer belongs to the execution task that claimed it (`semantic_query_memo/tasks.rs`), so same-path recursion is the claiming task finding its own producer open; a synchronous entry waits a subscription out on the flight's `Condvar`.
- `ComponentMetaResultDb<ComponentMetaAnalysis>` — final payload cache for `get_component_meta`. Warm hits revalidate the recorded `ReadSetSignature.facts` fact signature against the live `StoreView` before returning.
- `IntrinsicRegistry` — authoritative table for `= intrinsic`
  declarations. Intrinsic dispatch routes through
  `IntrinsicRegistry::lookup`; the SDK audit test asserts every
  `= intrinsic` declaration in `lib*.d.ts` has a registry entry.
  `ProjectSemanticDispatch` consults it before the `BuiltinUtility`
  fallback.

Dep-signature semantics: every reusable cache read returns a `CacheRead<T>` carrying the touched fact fragment. Callers merge those into the active `CompletionFence`, which bounds retries at 3 and publishes `UnstableState` when mid-flight invalidation persists.

Nested flow descriptors retain linked, content-free defining-frame gates over shared skeletons and exact binding maps. Value, type, namespace, and binder queries preserve the lexical position without copying every visible declaration. Only graph-selected captured identities request mutable declaration authority: reuse the exact source-declaration product first, then use `DeclBodyMemo::flow_capture_authorities` for batched transient hydration under one retained-source lease. Exact indexed binding spans prune syntax intervals and binary-search authored sibling lists; linked contexts and annotation locators must match the original whole-source snapshot. The locator preserves both the authored declaration and runtime capture identity, plus the original frame's lexical gate; semantic lowering uses that frame's binder environment, including through intermediate closures. Signature-only children never lower capture annotations or child bodies. An absent annotation differs from a locator/version failure. Complete selected declared/reaching/assignment inputs before hashing the child basis, then import that same immutable bundle at the child's graph-owned captured hubs; annotation hydration never credits an enclosing initializer.

The product execution indexes installed declaration authority by canonical runtime storage group. `FlowProductStore::declared_type` first reads the exact authored cell, then the minimum source-ordered installed alias; an absent group is a constant-time result. Publication updates only an address summary alongside the append-only authoritative cell. Multiway reaching definitions merge sorted input streams once, check width before admitting each distinct definition, and publish one canonical carrier.

Binding-value obligations expand only for the sealed selection's value subjects. Each captured binding obligation records `FlowCaptureDemand::Value` or `Effect` from that expression site's exact read footprint; a separate reader site does not change a writer site's requirement for their shared hub. Effect evidence requires completed selected structural execution and the exact closure dependency, without synthesizing reaching values, reaching types or definite-assignment products. The result-contract identity versions these proof semantics.

**The capture obligation identity is the CALLBACK, not the expression site.** A site can hold several authored callables — a call's argument list and an array literal are single sites (`f(() => a, () => b)`, `[() => a, () => b]`) — so `SkeletonExprSite.capture_bindings` is a deduplicated site-level UNION that answers "is this cell retained here", never "which callback retains it". `SkeletonExprSite.closures` is the per-callable partition: one `SkeletonClosure` per authored callable, in authored order, carrying that callable's own captures (transitive through its own nested callables; a read binding no declaration is free and never a capture) plus a `SkeletonClosureCorrelation`. Expansion emits `FlowObligationBasis::CapturedBinding { site, closure, … }` per (callback, captured binding); a callable the authority proved captures nothing emits the POSITIVE `CaptureFreeClosure`, so "capture-free" is a discharge rather than the same silence as an unenumerated callable; and a callable the indexed program does not serve (a parameter-default callable — the parameter-default environment is a separate scope the function index does not index as a lexical child) emits `UncorrelatedClosure`, which installs directly in the capture family's `FlowGap::ClosureCapture` and never reads as capture-free. No index record serves a class (its constructor, member bodies and field initializers) either: a class expression records an `Uncorrelated` closure on its site, and a class declaration's binding installs the same `Capture` gap as a nested function declaration. `FunctionProgramEntry::captures_exhaustive` is false when a frame, or any callable nested in it, creates such an unserved callable (a class or a parameter-list callable); a correlated callable with a non-exhaustive record is `SkeletonClosureCorrelation::Partial` and emits its named `CapturedBinding`s plus a `PartialClosure` that installs in the same gap, never `CaptureFreeClosure`. The skeleton walker must reach every evaluated position the index walks: binding patterns (declarators, iteration declarators, catch and formal parameters) open their computed keys as sites alongside their defaults, so a callable authored in `const { [reg(() => a)]: x } = o` is enumerated rather than invisible. Enumeration alone is not enough — the site must also be on the demanded slice: every binding of a pattern lists those sites as `SkeletonBinding::pattern_sites`, and the graph gives the binding an unconditional `EvalEffect` edge to each, so demanding any binding of the pattern selects them. Every other evaluated child site reaches the slice through its container: the graph's parent→child `EvalEffect` edge fires for a child whose effect closure holds a write, a call, OR a created callable (`SkeletonExprSite.closures` non-empty), because creating a callable retains its captures with no write or call footprint. So an object-literal computed key (`{ [() => a]: 1 }`), a closure-only sibling property under a narrower demand (`{ f: () => a, b: 1 }` demanded as `.b`), and a destructuring-assignment default (`({ x = () => a } = o)`, `for ([x = () => a] of o)`) are all selected whenever their container is.

`FlowBindingMap::occurrence(FrameSpan)` is the immutable runtime reference authority for exact identifier reads, writes and callees. It returns `Resolved`, known `Free`, `UnmodeledLocal`, or `Missing`; missing indexed evidence is a typed preparation failure and never enables name-based runtime resolution. Parameter default references retain their indexed outer environment. Nested capture footprints retain their exact indexed identities separately from current-frame occurrences. Class-evaluation occurrences use the same lexical scope index: outer-frame roots retain exact references; unsupported static-block locals and named-class-expression self names carry a typed `UnmodeledLocal` disposition. Static `var` declarations stay in their own static block. Whole writes to those locals do not target function products; calls through them cannot be certified as free calls. Deferred method bodies and instance initializers remain separate execution boundaries. Type-position lexical visibility (including `typeof` gates) remains separate from runtime occurrence identity; a type-name lookup never fabricates a runtime binding.

Flow call arguments and receivers retain the typed source origins emitted by the shared indexed lowerer while it produces their transient IR under the same retained-source lease. Resolve each occurrence once through its prepared `FlowBindingMap` authority: an ordinary identifier uses the runtime occurrence map, while a whole-root authored type query uses the separate source-type-query occurrence map. Both consume the exact queried subject's current narrowed or reaching type; only an ordinary value read may supply literal-freshness evidence. A type query never borrows its asserted operand's identity or manufactures runtime/effect evidence. Neither display-name scans nor synthetic point spans may recover a binding. The shared lowerer alone decides whether a value retains a binding root, including wrapped arguments and receivers; the session sidecar must not duplicate its wrapper policy. An explicit nonbinding disposition differs from missing observer evidence, which fails closed. Only selected catch subjects are initialized or scope-closed in the product adapter. Evolving lexical locals without an initializer or declared authority retain the existing conditional-definition policy through the shared definite-assignment product: conditional first definitions stay `ConditionalVarDefinition`/cold, while unconditional overwrites and joins with established entry values discharge that flag as before. Their exact lexical identity and scope cleanup never change to encode admission policy. Selected assignment definitions use the RHS span-to-site address retained from `FlowSliceIR`; no selected assignment rescans the frame write inventory. Duplicate spans with distinct sites cannot attach execution evidence.

The retained parse worker lazily owns an immutable `FunctionProgramNodes` address table beside the content-free function index. The same discovery and reference walk registers callable keys and evaluated call spans, including class-evaluation calls. A second self-cell owns a reference-counted parse cell, and `OnceCell` initializes its table once on index demand. Lease-bound higher-ranked callbacks read exact registered addresses and return owned results; production never re-enumerates sibling bodies to dereference a function locator.

Exact declaration addresses are prepared once by `FlowBindingMap::declaration_at_span`, with constant expected-time lookup by frame-relative identifier span. That lookup preserves authored declaration IDs, including distinct parameter/var redeclarations and shadowed binders; occurrence references and runtime aliases remain separate authorities. No content or parameter lowering may rediscover a declaration by scanning the frame inventory.

Shared indexed call lowering exposes opt-in `lower_indexed_call_expression_with_read_roots`: its observer receives each argument ordinal (including spreads) and the actual member receiver once during their existing lowering. `IndexedValueReadRoot::Identifier(Span)` is minted only by the value inference branch emitting that identifier read and forwarded through the existing value-preserving branches, including const assertions. Authoritative assertions keep their existing result and suppress operand provenance; an authored whole, single-segment `typeof name` without type arguments emits the distinct `SourceTypeQuery(Span)` origin at the shared type-query producer. That span belongs to the queried name, which can differ from the assertion operand. Primitive `undefined`, composites, and calls have no whole identifier root. `NonBinding` is not proof that names inside the result are free/module names. Ordinary indexed value/call APIs retain the same IR and use no observer, no provenance array, and no second AST classifier or walk.

Source type-query facts use the same content-free indexed assertion/unwrap disposition and inference carriers as actual lowering, preserving the existing const/satisfies precedence. The current-function index records each effective call-input query separately and resolves it through the existing lexical scope index. `FlowBindingMap::source_type_query_occurrence` distinguishes exact local/captured authority, known free, unsupported local and missing evidence without consulting runtime names. Prepared expression sites retain a separate query footprint; graph `SourceTypeQuery` edges share the value-definition frontier and consume the whole queried subject, resetting any inherited result projection. Query dependencies participate in hashing and normal selection/work budgets before the plan is sealed. They select the subject's current semantic type, including existing narrowing and reaching definitions, while creating no operand-read, effect, freshness or runtime-capture receipt. Member/generic/composite type-query inference and query-only transitive closure bridging retain their existing capability boundaries.

Runtime alias declaration groups are prepared once on `FlowBindingMap::runtime_declarations` and borrowed in source order. `runtime_shape` retains constant-size var/pattern facts so repeated reads can classify parameter/var aliases without rescanning their declarations. Graph reads, writes and capture subjects target one canonical runtime binding hub; that hub links each distinct authored declaration once so alias fanout never multiplies access edges. `FunctionProgramIndex` retains exact key, value-function and nested-position indexes; keyed retrieval and stable-hash remapping reuse those indexes without scanning unrelated functions.
