## Semantic Dispatch (current authority)

**Architectural decision:** `ProjectSemanticDispatch` +
`SemanticGraphStore` are the canonical lazy semantic layer and the sole
authority for every reusable type-resolution operation. The
`verter_semantic::analysis::type_solver` namespace now contains shared data
carriers only; its former solve, relation, and projection execution modules are
deleted.

The reusable semantic layer lives in
`crates/verter_session/src/project_semantic_dispatch/`. Each sub-module owns
a distinct responsibility:

- `mod.rs` — `ProjectSemanticDispatch` struct + `SemanticQueryApi::execute` impl
- `build.rs` — `build_instantiate`, `build_mapped_type`,
  `build_conditional`, `build_key_of`, `build_project_path`,
  `build_typeof`, `build_builtin_utility`
- `walk.rs` — `PathWalker` + `walk_path` (iterative worklist per plan §2)
- `guards.rs` — `SubstitutionGuard`, `EvaluationGuard`, `WalkGuard`, `KeyEnumerationGuard`, `RelationGuard` (per-call RAII cycle detection)
- `enumerate.rs` — `KeyEnumeration`, `EnumeratedKey`, `key_names_*` helpers
- `relation.rs` — the SOLE relation authority (`execute_relate` riding `execute(SemanticQueryKey::Relate)`): reentry/assumption frames, coinductive SCC discharge, inference sessions, the O(tag) prefilter, and the structural reducer; `relation_txn.rs` carries the transient `CheckerTransaction` substrate. THREE `RelationKind`s are live and reduce here, `Relate` staying the sole query tag: `Assignable` (the full structural lattice — what call applicability asks, unchanged), `Identity` (`reduce_identity`, BOUNDED to the nominal axis: two `unique symbol` declaring identities decide, every other subject is undecided — scope-insensitive STRUCTURAL constituent identity is the canonical type algebra's own comparator, not this relation), and `Comparable` (`reduce_comparable`, the overlap oracle: `NotAssignable` is a PROOF of empty overlap, `Assignable` means no such proof was found, `Unknown` means a subject the oracle could not read). `Subtype` / `StrictSubtype` are REFUSED (undecided, `ReturnOnly`) rather than answered through a neighbouring kind's lattice. `Identity` is live and warm-admittable but has NO production asker yet — `nodes_comparable` is the only new consumer and it asks `Comparable` — so its only current traffic is test-driven. Read its bound before reaching for it: `Identity(X, X)` is UNDECIDED for any non-nominal `X`, because scope-insensitive structural constituent identity is the canonical type algebra's own comparator and answering it here would be two engines for one question. `relation_nominal_identity` / `relation_nominal_leaf` are the nominal axis, asked before the deferred gate so a preserved `unique symbol` `typeof` carrier is not swallowed as an ordinary deferred shell. Mixed pairs are relation- and direction-aware: comparability widens either nominal side, while assignability widens only a nominal source; a broad `symbol` source never satisfies a nominal target.

  **The `expand_pair` gate ORDER is an invariant.** The nominal leaf sits directly ABOVE the deferred-shell gate and NOTHING else moved: the opaque gate, the `Infer` deposit, the `InferRef` gate, and the union/intersection distribution keep their positions, so a pair the nominal axis has nothing to say about takes exactly the sequence it always did. Re-hoisting the deferred gate above the nominal leaf would swallow every preserved carrier; sinking it below the distribution arms would decide composites-with-deferred-children the engine deliberately defers, which is a general change to the lattice and not a nominal one. The leaf DECLINES (returns `None`) when the non-nominal side is a composite — in EITHER direction, so a symmetric question cannot answer differently by operand order — or, for assignability only, when it is an `Infer` position that must receive the carrier verbatim as its inference candidate; a declined pair carrying a nominal identity is the ONE pair allowed to step over the deferred gate, so it reaches the frame that owns it. For the same reason `relation_eval_requires_canonical_frame` opens a memoized frame for a `DeclRef` / `InstantiationRef` / declaration-or-recursive placeholder ONLY when the pair's other side is nominal (a `Conditional` always opens one): a carrier's declaring identity is revealed only by the canonical frame's identity unwrap, and widening that to every carrier pair would decide array elements, tuple elements, and object members the deferred gate answers `Unknown` today.

  Comparable member descent uses one iterative worklist and one relation budget, so member checks neither recurse on the Rust stack nor open nested memoized relation frames, the worklist's frame-local memo and coinductive set key the CANONICAL (lesser-first) unordered pair, and trivial pairs (nominal leaf, interned-equal, tag-conflict) are decided on an ALLOCATION-FREE fast path before the work vectors and memo tables exist. An operand the oracle did not itself read — UNRESOLVABLE (`Opaque`, an unsubstituted `InferRef`, a bare / imported / declaration reference that survived the identity unwrap, i.e. a name that did not resolve) OR an UNREDUCED OPERATOR (`TypeOf` / `KeyOf` / `IndexedAccess` / `Mapped` / `Conditional` / `RawFallback`) — reports NO fact: undecided, `ReturnOnly`, zero admission. The permissive arm is a promise that no proof of empty overlap was found, and an unread operand cannot back it — answering permissive would convert missing knowledge into a warm-admissible positive. `reduce_identity` / `reduce_comparable` read ONLY the node pair, so both REFUSE a key whose substitution, inference-context, or freshness axis is non-default rather than publishing an answer under an axis they never consulted. The object descent COMPOSES a composed root first: a terminal `Object` node already is its surface, but an `Intersection` body or an `ObjectSpreadProgram` has no members until its arms merge, so those route through the single shared empty-path `Shallow` surface reader (`resolve_typeinfo_surface_view`) before the member descent — otherwise `Base & { kind: "a" }` versus `Base & { kind: "b" }` would take the permissive arm and the discriminated-union proof would be lost. A composition that yields no surface stays permissive, so no proof is minted from a surface the oracle could not read; `Alias` / `MergedDecl` roots never reach the classifier because the identity unwrap already flattened them. The member-descent budget charges the comparisons it actually performs: one unit per source member step PLUS the target-surface width per key projection (the projection scans the target's members), so a single descent cannot perform O(source × target) comparisons inside a linear budget. A negative `Comparable` verdict is handed out as `ComparabilityVerdict::Disjoint(DisjointnessProof)`, whose fields are private to `relation.rs`, so the proof is mintable ONLY by the authority. That privacy is a SUPPORTING constraint, not the enforcement: the consumer decides by elimination (`let ComparabilityVerdict::Disjoint(_) = … else`), so a re-introduced private classifier would branch on a bare `bool` and never construct the type. What actually holds "flow owns no relation classifier" is BEHAVIOURAL — the narrow populates the shared `Comparable` memo family, issues zero `Identity` judgements, and publishes a value only the authority's own descent produces. The proof carries the CHECKER'S intersection-collapse class for the queried pair (`DisjointnessProof::checker_reduces_intersection_to_never`, minted only inside the relation module): disjoint tags, distinct nominal identities, or a conflicting shared REQUIRED member whose values are BOTH unit types reduce the intersection to `never`; a conflict reachable only through non-unit member values — at ANY depth — KEEPS `A & B`, exactly as `tsc`'s `getNarrowedType` keeps `{ m: { b: number } } & { m: { b: string } }`. The flow consumer reads the class off the authority-minted proof and decides nothing about collapse; whether an intersection collapses remains the canonical algebra's policy, and the class is the interim checker-compatible boundary. Cycles: assignability re-enters the full authority for every sub-relation, so a re-entered pair goes through the transaction's obligation / re-discharge machinery; comparability's member descent stays in ONE frame and carries its own coinductive assumption — a re-entered pair is assumed to OVERLAP. Both folds propagate permissiveness, so an assumption can only miss a proof and never mint one, and a frame-local memo entry finished under an assumption carries only that same permissiveness forward. Only the ROOT pair is published to the shared memo, so no assumed sub-result escapes the frame that made the assumption.
- `lower.rs` — `shallow_lower_type_expr` (TypeExpr → `SemanticNodeId`); decl-body lowering is carrier-preserving under `Shallow` / `Navigate` / `Skeleton` (see Query Mode Contract)
- `substitute.rs` — `substitute_semantic_type_param` (guarded)
- `evaluate.rs` — `evaluate_deferred_semantic_node` (guarded)
- `origin.rs` — origin-edge emitters

**Builtin settlement in `build_builtin_utility`.** `NonNullable<T>` is implemented: a settled union filters its nullish arms (an emptied union ⇒ `never`), settled non-nullable shapes pass through unchanged, nullish primitives reduce to `never`, and an UNSETTLED operand keeps the deferred `Opaque(Miss)` shell. `Awaited` is routed by its PROVEN `BuiltinUtility::Awaited` identity to the LIB conditional (`lib_awaited_node`): nullish passes, `object & { then(onfulfilled: infer F, ...) }` infers from the LAST `then` signature and distributes over `F`, a callable `then` with no callable `onfulfilled` is `never`, an optional or non-callable `then` leaves the operand, and a generic operand keeps the authored carrier. It is NOT the compiler's runtime `AwaitedNormalize` relation (`await x`), which unions every `then` signature, types a malformed thenable `any`, and defers an open binder to `IntrinsicApplication(Awaited, [T])`; both read every `then` signature and every callback parameter through the ONE shared authority — `SignaturesOfType(subject, Call, ctx)` for the signatures and the positional accessor (`shared_positional_reads`, over `PositionalShape`) for the argument at a position — so neither carries a private signature reader. That accessor owns receiver exclusion (a `then(this: X, cb)` reads `cb` at position 0, never `X`), the leading-rest element read, and the nullish-arm split; a rest run with a required tail and a still-generic rest are incomplete reads, never an invented type. The RUNTIME relation additionally filters `then` signatures by receiver ELIGIBILITY through the relation authority (an operand not assignable to a declared `this` drops that signature; all dropped ⇒ malformed ⇒ `any`, tsc TS1058), which the lib conditional deliberately does NOT model. A UNION-valued `then` decides in both: the runtime relation reads the union's synthesized signature (its `onfulfilled` intersects the arms), while the lib conditional infers `F` per union constituent and unions the distributed arm results. A lib runtime nominal (`Function` / `Date` / `Promise<T>` / `Map<K, V>`) is an OPEN interface answered inside the shared discovery from its `declare global` contributors, so an augmentation reaches every consumer, not just the awaited readers. The async return payload is the separate `AsyncReturnPayload` family (a naked type parameter is its own payload). (Note: `NonNullable` still makes NO closed-KEY-domain claim for the L1 key-domain predicate — value-producing utilities stay conservatively not-provably-closed there.)

`SemanticGraphStore` (crate `verter_session::semantic_query_memo`) owns all reusable semantic identity via two parallel memos:

- **Node memo** — mode-erased `FamilyKey` → `FamilySlots` map for single-node queries (`ResolveDecl`, `Instantiate`, `KeyOf`, `MappedType`, `Conditional`, `ProjectPath`, `TypeOf`, `ReduceUnion`, `ReduceIntersection`, `ResolvedNamedType`).
- **Relation memo** — keyed by the full-identity `RelateMemoKey` (source / target / relation kind / policy / source freshness / inference context / env+substitution+projection-reduction context) for `Relate` judgements. Admission is decided-only: only the binary `Assignable { bindings }` / `NotAssignable` payloads publish (cache-with-fence); `Unknown`, `BudgetExceeded` (public payload, `cache_suppress`), session-local inference deltas, and abandoned sessions publish NOTHING — no memo entry, no fact signature, no reverse index.

### Object-literal spreads: canonical construction programs

Every spread-bearing object is a `SemanticNodeData::ObjectSpreadProgram(ObjectSpreadProgram)` — one immutable, source-ordered effect list (`DirectProperty` / `DirectMethod` / `DirectGet` / `DirectSet` / `DirectIndex` / `DirectCall` / `DirectConstruct` / `Spread`). It is the sole stored description of the object: no folded member surface, completeness mirror, replay cursor, or side log coexists. A non-spread object stays a closed `SemanticNodeData::Object` surface (every `SurfaceView` is closed by construction; the open-operand representation is gone). Direct effects carry lossless typed facts: typed key or computed-key child, value/signature children, optional/readonly, method/get/set kind, implementation-body fact, visibility, spans/declaration origin, and excess origin.

Typed property keys flow end to end: `PropertyKey = String | Number(CanonicalIndexInt) | UniqueSymbol(DeclIdentity)`, and `AuthoredPropertyKey = Known(..) | Computed(child)`. Identifier/string-literal equivalence is centralized; numeric keys use the checked canonical-index rules; unique symbols compare by nominal declaration identity, never display spelling; unresolved computed keys stay typed children (they are never stringified). Element access coerces a numeric key and its canonical string spelling; `keyof` keeps the authored variant. A key no property names reads the index signature that applies to it (the path walker's `index_signature_read`, TypeScript's `getApplicableIndexInfo`: a non-`string` index whose key type the key is assignable to through the relation authority, several intersecting, else the `string` index; a symbol key falls back to the `string` index as the checker recovers from TS2538). The order is the checker's `getIndexedAccessType`: a string-index-only object reads its `string` index for any key assignable to `string | number`; any other object reads its own property, then the members its apparent `Function` type (call or construct signatures) and the global `Object` add, then the index signature; a heritage body is read off its composed surface. A union or intersection splits its arms with an `ArmRead` (intersection arms read their own properties, union arms read as union members: own, apparent, applicable index) and each arm reports, through its own step, the surface it settled on (`PathWalker::arm_probes`); when no arm declares the key the join decides for the composite (`PathWalker::composite_hop`: the composite `string` index, an intersection's apparent members, or the composite's index signatures — every arm's for an intersection, the key types every arm declares for a union). A tuple or array arm reports its `Array` wrapper surface (a tuple declares its fixed positions and `length`, an array no position); a union or intersection arm reports itself, and the join reads the composite the checker constructs over it (a union flattened, an intersection distributed over a union arm through `distributed_intersection`); an intersection arm of a union is one object, its composed surface. The arm steps are the only resolution of the arms; the decision reads only the apparent surfaces it needs. A `#private` class brand is not a type-level member.

`ExcessPropertyOrigin` still participates in canonical node identity (`Eq` / `Hash`), not request-local metadata. Direct literal writes are `FreshOwn`; spread-introduced or spread-overlapped members are `SpreadTainted`; all other origins are `NonLiteral`.

The fresh excess-property prepass is a dormant engine capability. No production caller constructs a relation ask with `excess_property_check: true`; non-test policy and oracle plumbing default the flag to `false`. Direct relation-level tests exercise the capability, but only a future production caller explicitly setting `excess_property_check: true` on a fresh-source relation activates it in production.

**One correlated projection family.** `SemanticQueryKey::ProjectObjectSpread { program, selector, context }` evaluates programs. Selectors: `Key`, `RelationShape`, `Surface`, `IndexDomain`, `Signature`, `EnumerableValueEnvelope`, `ExcessEligibility`. The sealed dispatch-constructed context carries the projection-reduction axes, the R/T/L/J environment hashes, the substitution identity, and the exact-optional-property policy; prepared and family identity include all of them, so distinct selectors/environments/views never cross-serve.

Finite enumerable union operands fork whole alternatives at their exact spread position, and later effects apply per branch, so correlation survives overwrites. Selector liveness prunes only shadowed recursive effects before recursion (`Key(x)` on `{...Self, x}` never enters `Self`; `{x, ...Self}` must). An alternative's public surface is positive evidence only: omission never proves absence, emptiness, exact `keyof`, exhaustive domain, or closed materialization. Those operations exist only on the sealed witnesses `ClosedObjectProjectionAlternative` / `ClosedObjectProjectionFormula`; an open or mixed formula cannot mint one.

Optional spread writes fold per branch: absent + optional → optional right-present value; required/optional left + optional → required/optional union of presents; a live open residual keeps presence but makes value/facets indeterminate; a later required direct write restores exactness. The exact-optional policy controls authored `undefined` (`1|2` vs `1|2|undefined`), and environments never cross-hit. Spread-copied index facts lose readonly; authored direct indices keep it. An index constrains values when a key exists but never manufactures named presence. Direct call/construct effects survive in distinct buckets; a callable/constructable operand contributes neither.

**Excess eligibility is a whole-program selector**: `Eligible { direct_candidates }`, `SuppressedByGenericSpread`, or `Indeterminate`. Any semantically generic spread suppresses all direct candidates before or after it (even under a finite-looking constraint); closed/enumerable spreads do not suppress and spread-provided keys are never candidates; operational inability to classify a residual is `Indeterminate`, which falls back safely (no rejection). Generic-to-concrete substitution re-evaluates eligibility. The prepass consumes programs through this selector and requires closed alternatives for absence.

**Relation consumes correlated alternatives with exact quantifiers**: every source alternative must assign to some target alternative; reject only with complete negative proof; open/indeterminate evidence falls back to `Unknown`. Program roots are recognized before self-equality, shortcuts, inference deposits, excess, `Record`, index, and signature loops. `{...T} <= {...T}` stays non-publishing `Unknown` while `T` is unresolved, despite identical node ids. Required named target keys need named required presence — a source index never satisfies it. Broad `Record`/index obligations relate every known contribution and require an exact envelope per live residual; open targets reject on exact known mismatches before closure but stay `Unknown` on a passing known subset. Inference deposits only from exact whole-branch positions inside the existing transaction checkpoints — indeterminate positions deposit nothing. Alternative-product caps, depth caps, and recursive breaks are typed operational partials (`BudgetExceeded` / recursive), ReturnOnly and admitted nowhere; a later adequate run heals. Cross-thread owner wait-cycles break with a typed recursive partial under the store's owner wait-for graph.

Raising/display preserves exact effect order when no closed formula exists (never spreads-first); the shallow typeinfo surface joins positive members with `members_complete = false` unless a single closed alternative proves the domain. On the wire, `GraphObjectSpreadProgram` (tag 33) carries the ordered lossless effect list under graph schema 7.

**Canonical deferred forms** (plan §2 — only these variants cross any cache boundary):

- `SemanticNodeData::Mapped { source, mapper }` — deferred mapped type
- `SemanticNodeData::Conditional { check, extends, true_branch_ref, false_branch_ref, distributive }` — deferred conditional
- `SemanticNodeData::IndexedAccess { object, index }` — deferred indexed access
- `SemanticNodeData::KeyOf { base }` — deferred keyof
- `SemanticNodeData::TypeOf(carrier::TypeOfCarrier)` — deferred typeof (opaque payload; head fields `value_root`/`path` via `typeof_head`, args via `carrier_type_args`, rebuild via `map_carrier_type_args`); the nominal `unique symbol` terminal is the SEPARATE `SemanticNodeData::TypeOfNominal(carrier::TypeOfNominalCarrier)` variant (identity via `typeof_nominal_identity`, no args to rebuild)
- `SemanticNodeData::TypeParam { name }` — open type parameter reference
- `SemanticNodeData::Alias(target)` — alias identity preservation (target must be `DeclAnchor`-identifiable — plan Change B)
- `SemanticNodeData::Opaque(err)` — genuine projection miss or structured budget failure
- `SemanticNodeData::Signature { kind: SignatureKind::{Call,Construct}, params, return_type, type_parameters }` — the ONE signature shape for call (`(…) => R`) and construct (`new (…) => R`) signatures; kind participates in node identity, `Call` raises to `TypeExpr::Function` and `Construct` to `TypeExpr::ConstructorType`; class/interface lower to `Object` with heritage merged (a class's construct bucket holds `Signature(Construct)` nodes)
- `SemanticNodeData::Infer { name }` vs `SemanticNodeData::InferRef { name }` — representation INVARIANT: an infer DECLARATION (`Infer`, the literal `infer X` binder in a conditional's `extends` pattern) and an infer REFERENCE (`InferRef`, a use of the bound name — e.g. a true-branch `X`) are DISTINCT node kinds and must never intern identically. The distinction is load-bearing for capture-avoidance: the conditional substitution arm's shadow stop keys on a literal `Infer` DECLARATION in a nested conditional's own `extends` pattern, so collapsing references onto the declaration node would either capture a genuine re-bind or drop a legitimate outer substitution. The literal `infer X` syntax is the ONLY producer of an `Infer` node; name bindings hand out `InferRef` nodes.

All surrogate encodings are retired: `Alias(KeyOf(source))` (replaced by canonical `Mapped` shell with `KeyEnumeration::Unresolvable` branch), arena `Node::Error { description }` used as a materialisation sentinel, `Primitive(Undefined)` returned from failed solver projections.

**Parser → semantic graph integration.** Parser output is syntax-only route
inventory. `route_inventory.rs` records authored imports, exports, reexports,
and export assignments. From the same retained program and exact owner table,
semantic `ScriptShallowIndex` pairs those routes with `DeclHeaderIndex`, while
semantic `decl_dependencies` produces per-declaration dependency names on
demand. The indexed lowering service converts authored declaration bodies into
owned typed IR on demand; semantic queries then enter
`ProjectSemanticDispatch::execute`. No parser cache adapter stores or returns
resolved type surfaces.
