# V9 — Measured semantic storage optimization

Readiness comes only from trusted implementation-ledger rows. A READY node may start; tooling does not validate commit locators, Git identity, receipts, leases, external state, or runtime admission.

Normative contract: `contracts/signature-kernel.md` sections 11.5 and 13 (V9). This block is conditional: it is dispatched only when V8's measurements justify it or when V8 records that the lifetime gate requires it before release.

## Independently acceptable outcome

Semantic storage is reclaimed more efficiently on measured workloads — through live-graph compaction, regional retirement, or live-result migration — while epoch identity, root closure, record-reference remapping, evidence validity, and old-reader safety are preserved and fresh/warm/replay semantics are unchanged. One independently acceptable outcome; no subblocks.

## Concrete surfaces and APIs

- `crates/verter_session/src/signature_kernel/storage.rs` and `lifetime.rs` (V2), `semantic_query_memo/arena.rs` (`NodeArena`), and the graph-epoch replacement path; mechanically isolated from any semantic change.
- Mutation boundary: those surfaces and their test homes; no query-key or producer change.

## Exact predecessor contracts

- **V8:** implemented ledger row with published profiles naming the measured cost this block solves.
- **External requirements:** none.

## Source-specific scope

- The workload and budget rows in `catalogs/semantic-memory-budget.toml` registered by V0 are the acceptance instruments.

## Acceptance IDs and discriminating proof

- **V9-AC1 — reclamation:** reclaimed bytes and reclamation tail latency improve on the matched workloads against V8's published numbers.
- **V9-AC2 — semantic invariance:** the signature corpus, determinism matrix, and fresh=warm=replay suites are unchanged.
- **V9-AC3 — safety:** no stale id, hidden root, or old-reader fault under the concurrency/lifetime rows (epoch replacement with an old reader, snapshot-scoped coalescing, waiter cancellation, id overflow).
- **V9-AC4 — no read tax:** the warm positional read path adds no per-read cost (allocator and lock canaries).
- Test homes: `signature_kernel/*_tests.rs`, `tests/cases/allocator_canaries`, `semantic_determinism_matrix.rs`, benchmark manifests.

## Deletions and forbidden designs

- No semantic change; no relocation of live handles that invalidates external stable locators; no permanent exemption from bounded storage.
- Do not implement successors or silently enlarge this charter.
