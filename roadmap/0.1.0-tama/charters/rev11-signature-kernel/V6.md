# V6 — Call, construct, utility, and flow-intersection cutover onto the kernel

Readiness comes only from trusted implementation-ledger rows. A READY node may start; tooling does not validate commit locators, Git identity, receipts, leases, external state, or runtime admission.

Normative contract: `contracts/signature-kernel.md` sections 10.3 and 15.

## Independently acceptable outcome

Every call, construct, signature-utility, callable-classification, and flow-intersection consumer reads the shared kernel: `ResolveOverloadSet`/`ResolveCall` consume `SignaturesOfType` candidates and apply call-site ordering, applicability/inference (kept in their existing owner), and one frozen call substitution; per-arm union-call acceptance is removed in favour of the kernel's common/synthesized union signatures; the six signature utilities route through one keyed path; flow intersection producers call `ReduceIntersection`; and a generic call substitutes its return exactly once. One independently acceptable outcome; no subblocks.

## Concrete surfaces and APIs

- Calls: `crates/verter_session/src/project_semantic_dispatch/build.rs::build_resolve_overload_set` (`:1924`) consumes `SignaturesOfType`; the arm-flatten stack (`:1955-1975`), the composite-union branch (`:1976-2032`), and `settle_signature_group` (`:2095`) are deleted. `call_resolve.rs` — `arm_ordinal`/`arm_states` derivation (`:1146-1176`) and the `UnionSelected` merge (`:1257-1327`) are removed; `ResolvedCallResult::UnionSelected` is retired; contextual applicability/inference stays in `check_call_candidate`; the return is produced by `ReadSignatureResult` under the frozen `CallSubstitutionId` — the descriptor-seed + result re-substitution + widened re-take + binder probe sequence (`:2049-2204`) collapses to one application; `apply_typeof_instantiation_args` on the raw candidate is replaced by descriptor instantiation.
- Utilities: the string-matched arms for `ReturnType`/`Parameters`/`ConstructorParameters`/`InstanceType`/`ThisParameterType`/`OmitThisParameter` in `build.rs:5573-5670`, the shortcuts in `absorb.rs:342-355`, the name list in `mod.rs:2189-2194`, and the ad hoc checks in `carrier.rs:344` and `flow_return.rs:1142/1148/14680` are replaced by one keyed utility path over `SignaturesOfType` + the positional model (last-signature inference as a documented mode); `select_signature_function`, `select_signature_function_inner`, `signature_bucket_arity`, `signature_bucket_arity_inner` (`build.rs:6264-6417`) are deleted.
- Callable classification: `apparent_type.rs::callable_anchor`, `walk.rs::value_may_contribute_call_signatures`, `broad_runtime.rs:261`, and the `ApparentType` callable arm delegate to `SignaturesOfType` (thin adapters only where they make no semantic decision).
- Flow: `flow_return.rs:13391 call_return_of_callee_node`'s `>1 signature` degradation is removed (the kernel resolves); predicates and assertions flow from `ReadSignatureResult` effects into the existing narrowing (`narrow_to_predicate_target`); `FlowReturn` reuse for body-derived results is unchanged. Flow intersection producers — `flow_return.rs:10248, 10522, 10689, 10706`, `flow_return_callee.rs:669`, `relation.rs:2371`, `walk.rs:3821/4166/7076`, `substitute.rs:343`, `meta_resolve/callable_view.rs:885/1051`, `meta_resolve/dispatch_helpers.rs:215`, `locator_view_worklist/finish.rs:207` — call `ReduceIntersection` with the relevant purpose; the ordered-carrier mints in `walk.rs:3813/7073` and `build.rs:4774` become `IntersectionInputRef` recipes.
- Generated output: the existing type-text generators and public serializers (`typeinfo`, component-meta `TypeExpr` projection, signature-help rendering) consume the stable union order and deterministic member traversal; exact generated bytes are pinned under fixed output options.
- Mutation boundary: those surfaces, the corpus/coverage tests that pin them, and registries/mirrors forced by retired variants.

## Acceptance IDs and discriminating proof

- **V6-AC1 — single consumer path:** every migrated consumer agrees on its common semantic inputs (a differential test over the corpus compares call, utility, and flow answers for the same callee); no private callable/intersection synthesis remains (structural: the retired helpers do not exist).
- **V6-AC2 — warm synthetic results:** a dependency-rooted synthesized union/intersection signature admits warm and replays equal to fresh.
- **V6-AC3 — diagnostics per site:** two call sites reusing one synthesized signature receive their own locations without rerunning unrelated type work (counter).
- **V6-AC4 — one substitution:** a generic call with a body-derived return executes `FlowReturn` once and applies the call map once (counters `flow_return_count`, substitution count); generic return maps compose in the defined direction.
- **V6-AC5 — flow effects:** predicates/assertions from kernel results narrow correctly; body, type, option, and order-policy edits invalidate exactly the consumed work; shape-only and annotated demands force no bodies.
- **V6-AC6 — generated bytes:** the pinned type-text and typeinfo outputs are byte-identical across the determinism perturbations.
- Test homes: `call_resolve_tests.rs`, `flow_return_coverage_tests.rs`, `signature_corpus_rows_tests.rs`, `u6_flow_shape_corpus_rows_tests.rs`, `tests/cases/g_block/semantic_determinism_matrix.rs`, typeinfo snapshot tests.

## Deletions and forbidden designs

- Delete the helpers and branches named above, `ResolvedCallResult::UnionSelected`, and the five utility name-match sites; no thin adapter that makes a semantic decision; no per-arm union acceptance retained as a fallback; no second substitution pass.
- Do not implement successors or silently enlarge this charter.
