# V0 — Signature-kernel evidence lock and acceptance registration

Readiness comes only from trusted implementation-ledger rows. A READY node may start; tooling does not validate commit locators, Git identity, receipts, leases, external state, or runtime admission.

The train's normative contract is `contracts/signature-kernel.md` (Verter Semantic Signature Kernel, revision 4.1) plus its checkout-binding appendix. Where this charter and that contract disagree, the contract wins.

## Independently acceptable outcome

The evidence lock exists and is executable before any semantic cutover: the contract is checked in with exact input hashes; the oracle is pinned to TypeScript 7.0.2 native (`typescript@7.0.2`, platform package `@typescript/typescript-<platform>@7.0.2`) with the compiler executable and every shipped `lib.*.d.ts` digested into a committed manifest; every recorded oracle column in the tree that cites tsgo `7.0.0-dev.20260526.1` is re-measured under 7.0.2 and ported (identical answers keep the row, differences update the column and land in the semantic-difference ledger as `independent semantic difference` rows until classified); a new signature observation corpus with its own identity is generated against 7.0.2 (never presented as the unrecovered 9,300-case report); the section 5.9 determinism perturbation matrix, the section 5.4 stable-key category/encoding table, the four-class semantic-difference ledger, and the memory/soak/performance budgets are registered as data plus an executable harness whose not-yet-satisfiable rows are `#[ignore]`d with the owning successor block named in the reason. One independently acceptable outcome; no subblocks.

## Concrete surfaces and APIs

- Contract and evidence: `roadmap/0.1.0-tama/contracts/signature-kernel.md`; `docs/evidence/signature-kernel/manifest.json` (contract SHA-256, oracle package versions, executable and lib digests, corpus seeds, generator version); `docs/evidence/signature-kernel/semantic-difference-ledger.md` (classes: exact agreement, presentation-only, `VerterStableV1` order-induced with causal proof, independent difference/incompleteness).
- Oracle generation: `crates/verter_session/src/typeinfo/oracle_core/` (`gen.rs`, `driver.rs`, `hover_extract.rs`, `snapshot.rs`) under the existing `oracle-gen` feature, extended to drive the 7.0.2 executable and to capture `--declaration --emitDeclarationOnly` output bytes beside hover observations. tsgo stays generation-only; `oracle_tsgo_forbidden.rs::tsgo_not_reachable_from_resolver` keeps holding.
- Corpus rows to port: `crates/verter_session/src/u6_flow_shape_corpus_rows_tests.rs` (`checker` column header and every row), the four oracle matrices in `crates/verter_session/src/project_semantic_dispatch/flow_return_coverage_tests.rs` (`awaited_relation_oracle_matrix`, `awaited_thenable_protocol_oracle_matrix`, `lib_awaited_conditional_oracle_matrix`, `awaited_callback_edge_oracle_matrix`), and the `Oracle (tsgo 7.0.0-dev.20260526.1 …)` doc rows in `meta_tests.rs`, `component_meta_flow_return_admission_tests.rs`, `crates/verter_semantic/src/analysis/function_program_tests.rs`, `flow_slice_content.rs`.
- New corpus: `crates/verter_session/src/signature_corpus_rows_tests.rs` (append-only `Row` table in the corpus style: source, probe, recorded 7.0.2 observation — signature count and order, kind, binders with normalized names, constraints and defaults, positional types and optionality, declared and effective minima, rest layout, receiver, return, predicate, diagnostics, selected representative — plus recorded declaration-emit bytes) and its driver `signature_corpus_tests.rs`. Families required by the contract's V0 gate: union-valued `then`, construct and mixin intersections, defaults and predicates, both substitution stages, preserved and transparent intersection groups, every Awaited residual family, and order-heavy generic unions.
- Determinism registry: `crates/verter_session/tests/cases/g_block/semantic_determinism_matrix.rs` — one table row per section 5.9 perturbation (forward/reverse/random arrival, lazy vs eager, unrelated interning first, worker counts 1/2/4/8 with randomized delays, cold/warm/persisted/edit-revert/cancel-retry/epoch rebuild, hash-seed and forced-collision, duplicate origins and anonymous/virtual units, contextual body demands, policy change with resident parents, relocation, deliberate authored reorder, unrelated preceding outputs) with a driver that replays the current implementation and compares completed observations and generated bytes.
- Budgets: `roadmap/0.1.0-tama/catalogs/semantic-memory-budget.toml` gains the kernel's workload rows (edit/revert soak, retired-epoch bound, reclamation tail latency, p50/p95/p99 latency and 1/2/4/8-worker throughput baselines) validated by `tools/validate-semantic-memory-budget.mjs`.
- Mutation boundary: only those surfaces and their test homes. No production semantic code changes.

## Exact predecessor contracts

- **D12:** implemented ledger row; its awaited relations and wrapper canaries are the baseline the ported oracle columns must still describe.
- **External requirements:** none. The 7.0.2 executable is a workspace dev dependency already present in the lockfile.

## Source-specific scope

- Record in the manifest that the reported 9,300-union / 56,548-observation corpus and its 7.0.2 artifacts were not recovered; the new corpus carries its own identity and seeds.
- The 7.1.0-dev nightlies are recorded as out of scope for this train (moving target; their content-mapper work is unrelated).
- A perturbation row the current implementation is known to fail (for example arena-order union projection, first-wins composite category) is registered `#[ignore]` naming the block that un-ignores it (V4/V5/V8); no row is an empty body or a trivially true assertion.

## Acceptance IDs and discriminating proof

- **V0-AC1 — evidence identity:** the manifest's digests reproduce from the checked-in inputs and the installed 7.0.2 package (`oracle_core::identity` test re-hashes and compares); a changed lib file or executable fails it.
- **V0-AC2 — oracle port:** every `checker`/oracle column cites 7.0.2; `oracle::every_row_records_the_checkers_answer` and `checker_column_cross_validates_against_live_rendering` stay green; a row whose 7.0.2 answer differs from the dev-measured one is listed in the ledger with both strings.
- **V0-AC3 — corpus executability:** the signature corpus driver parses every recorded observation and compares the current implementation's answers under a recorded per-row verdict (`MatchesChecker | KnownOwed | Degraded`), so a later block that changes an answer flips a row instead of a prose report.
- **V0-AC4 — registration:** the determinism table enumerates every section 5.9 row and the stable-key variant table enumerates every `SemanticNodeData` category; both are consumed by executable drivers, not documentation alone.
- Test homes: `crates/verter_session/src/signature_corpus_tests.rs`, `crates/verter_session/src/signature_corpus_rows_tests.rs`, `crates/verter_session/tests/cases/g_block/semantic_determinism_matrix.rs`, `crates/verter_session/src/typeinfo/oracle_core/`.

## Deletions and forbidden designs

- Delete the tsgo `7.0.0-dev.20260526.1` citation as an oracle authority everywhere it names a measured column (comments are updated to the 7.0.2 measurement; historical notes may say a row was first measured on the dev build).
- No production behavior change; no golden minted from a prose report; no `TypeScript` display string used as semantic identity; no runtime tsgo dependency.

## Budgets and mandatory rescope

- Target ceiling: 1,200 production LOC (generator and corpus drivers), 12 files, 2 crates. Mandatory rescope above 2,500 LOC, 20 files, or 3 unrelated crates, or if oracle generation would require a runtime provider dependency.
- Correctness budget: zero unverified digests, zero rows with an empty or undecidable observation.

## Abort conditions

- Stop before mutation if the 7.0.2 executable is not resolvable from the lockfile on the implementing host, or if `oracle-gen` cannot drive it hermetically.
- Abort on an oracle answer that cannot be captured deterministically across two runs.
