# V2 — Signature records, substitutions, and epoch-safe storage

Readiness comes only from trusted implementation-ledger rows. A READY node may start; tooling does not validate commit locators, Git identity, receipts, leases, external state, or runtime admission.

Normative contract: `contracts/signature-kernel.md` sections 3.2, 3.3, 3.5 and 11.

## Independently acceptable outcome

The kernel's records exist with measured layouts and a lifetime contract: input shapes, templates, descriptors with one declaration-instantiation environment, candidates, inline `Empty | One | Many` result sets, closed result recipes, explicit binder spaces, frozen call substitutions composed through the existing substitution authority in the defined direction, mapped constituent edges, provenance and overload-order metadata, a private append-only interner adapter on a pinned `boxcar` backend, and epoch-pinned request read views with real retirement support. No consumer is cut over here. One independently acceptable outcome; no subblocks.

## Concrete surfaces and APIs

- New module `crates/verter_session/src/signature_kernel/` — `records.rs` (`SignatureInputShape { kind, binder_declarations, this_parameter, parameter_layout, declared_minimum, signature_semantic_flags }`, `SignatureTemplate { input_shape, result_recipe }`, `SignatureDescriptor { template, declaration_environment: DeclarationInstantiationId, residual_binders: BinderSpaceId }`, `SignatureCandidate { signature, provenance }`, `SignatureSetRef = Empty | One(SignatureCandidate) | Many(SignatureSetId)`, `SignatureResultRecipe = Declared | Body(return_obligation_key) | UnionCommon | UnionSynthesized | IntersectionConstruct`), `substitution.rs` (`CallSubstitutionId`, binder-space-qualified, `compose_after(first, second)` with `apply(compose_after(a, b), T) = apply(b, apply(a, T))`, identity-map elision, chain-depth control, lazy projection onto referenced binders), `provenance.rs` (declaration-group identity, declaration-parent identity, source/overload ordinal, origin relationships, cached effective overload order; composite constituent sequences with arm identity), `storage.rs` (the private adapter over `boxcar::Vec`, 16 dedup shards as a benchmark parameter, hash outside shard locks, equality on collision, fully initialized before publish, checked overflow, no hole exposed on cancellation or panic), `read_view.rs` (`SemanticReadView` pinning one graph epoch and snapshot per request, borrowed immutable records, no per-candidate `Arc` clone or global lock), `lifetime.rs` (epoch ownership, roots = live project state + intentionally retained results + live readers, retirement/drain behavior, stale-handle rejection).
- Dependency: `boxcar` pinned in `Cargo.toml` at its verified release with recorded MSRV/target support (wasm32 included) in the V0 manifest.
- Parameter optionality is represented explicitly (`ParameterOptionality` carrying the effective `undefined` inclusion under the active context) — never reconstructed from a missing span.
- Layout assertions: `SignatureCandidate` 16 bytes, `SignatureSetRef` 24 bytes, plus measured `Ready`, outer `QueryOutcome`, hot family key, and persisted memo record sizes on 64-bit targets (`const _: () = assert!(size_of::<…>() == …)` plus a reporting test).
- Mutation boundary: the new module, `Cargo.toml`/`Cargo.lock`, and test homes; existing dispatch code is untouched except for `pub(crate)` seams the module needs.

## Exact predecessor contracts

- **V1:** implemented ledger row; `SemanticContextId`, `OutcomeEvidenceId` and `ResultEvaluationContextId` are the identities these records embed.
- **External requirements:** none.

## Source-specific scope

- Verify the `boxcar` release's initialization semantics and target support before relying on it; the correctness contract is the adapter's, asserted by its own tests.
- Full live-graph compaction is out of scope (V9); regional retirement or coherent epoch replacement satisfies this block's lifetime gate.

## Acceptance IDs and discriminating proof

- **V2-AC1 — layouts and interning:** the layout assertions hold; two descriptors built from the same template and normalized environment intern to one id; a body locator difference never shares a result recipe while sharing an input shape.
- **V2-AC2 — substitution laws:** applying a composed map equals applying its components in order; no double substitution on a warm read; no capture of a same-spelled binder; no escaping temporary inference variable; a repeated warm result read walks no historical descriptor chain (counter).
- **V2-AC3 — schedule-independent identities:** logical carrier and binder identities are equal across interning orders and worker counts (duplicate-publisher race test); no observable first-writer state on a shared record.
- **V2-AC4 — storage safety:** duplicate intern races, cancelled producers, checked overflow, and panic paths expose no uninitialized handle; a stale epoch handle is rejected; an old pinned reader finishes against its epoch while a new request uses the replacement.
- **V2-AC5 — read path:** no per-candidate `Arc` clone or global lock on the warm positional read (allocator canary + lock instrumentation).
- Test homes: `crates/verter_session/src/signature_kernel/*_tests.rs`, `tests/cases/allocator_canaries`, `tests/cases/g_block/semantic_determinism_matrix.rs`.

## Deletions and forbidden designs

- No hand-written unsafe container; no `M1 ∘ M2` without the application law; no second persistent instantiated result-recipe mapping; no transaction pointer, mutable inference context, or stack closure in a recipe; no per-edge owned `Vec` on the hot read path.
- Do not implement successors or silently enlarge this charter.

## Budgets and mandatory rescope

- Target ceiling: 3,000 production LOC, 30 files, 3 crates. Mandatory rescope above 6,000 LOC, 45 files, or 4 unrelated crates, or when concurrency/lifetime work is combined with a semantic cutover.
- Correctness budget: zero exposed holes, zero stale handles served, zero double substitution.

## Abort conditions

- Stop before mutation if `boxcar` cannot be pinned for every supported target (native + wasm32-unknown-unknown) or if measured layouts cannot meet the 16/24-byte targets without unsafe.
- Abort on unexplained allocation or lock-wait divergence in the read-view canaries.
