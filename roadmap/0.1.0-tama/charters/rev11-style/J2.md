**Two candidate second outcomes, named for the ruling rather than asserted
away.** The charter requires an amendment and a new DAG node BEFORE mutating
anything that is a second independently acceptable outcome. Two parts of this
candidate are arguably that, and the maintainer — not this candidate — decides:

1. **The `lang` spelling-owner consolidation.** Giving `CssDialect::from_lang`
   sole ownership of the spelling → dialect identity is what makes the named
   owner sole, so it is inside the charter's own thesis. But it reaches
   `verter_parser` and `verter_semantic`, and it FLIPS a user-visible answer:
   `<style lang="SCSS">` moves from `NativeAvailable` to
   `ProcessedContentRequired`. That flip is the point (no preprocessor table
   has that key, so nothing could ever build the block), yet it is an
   observable behaviour change outside the declared surfaces.

   The review fix round BOUNDED it: byte-exactness now applies only to
   spellings a preprocessor table is keyed by. `css` is matched
   ASCII-case-insensitively in both spelling owners, because plain CSS reaches
   no such table — nothing downstream can fail on its casing, the reference Vue
   pipeline compiles `<style lang="CSS">`, and failing it closed cost that block
   every CSS diagnostic, hover and colour with no agreement gained. So the flip
   is now exactly the preprocessor dialects, and `lang="CSS"` no longer
   regresses. The maintainer still rules on the outcome; the surface it covers
   is smaller than when it was first recorded.
2. **The VS Code CSS-service change.** It is simultaneously a new capability
   (preprocessor compile errors now surface as diagnostics, where they were
   collected onto a record nothing read) and a fail-closed narrowing (a `lang`
   naming no dialect at all is now served nothing instead of being validated as
   plain CSS). Either half alone would be ordinary ripple; the pair reads as its
   own outcome. The narrowing no longer reaches `lang="CSS"`, per the carve-out
   above.

Neither is presented here as pre-authorised. If the ruling is that they are
separate outcomes, the resolution is an amendment plus a DAG node, or a split —
not necessarily reverting the code.

## Requested DEFER — `STYLE-REFUSAL-SPAN-PRECISION`

Recorded by the implementation as a deferral REQUEST, with every element
`CLAUDE.md` → Fix Quality requires filled in as far as an implementer can. It
is not a ruling: the ruling and the durable owner block are the DAG/plan
maintainer's, and creating a DAG node is outside an implementer's mutation
boundary. Until it lands, this deferral is incomplete by its own terms.

- **ID:** `STYLE-REFUSAL-SPAN-PRECISION`
- **Finding:** once any earlier cascade stage rewrites bytes,
  `CascadeStageSpaces` marks later stages not-at-input, their refusals are
  tagged `StyleStage::FrameworkRewritten`, and `compile::push_style_diagnostic`
  anchors them on the whole content span. The common real shape —
  `<style scoped>` containing both a `v-bind()` and an untrusted selector —
  moves from a precise range to a block-wide one. The pre-change range was
  genuinely wrong for offsets AFTER the first edit, but correct for every
  refusal before it, so a subset of correct precision is lost.
- **Why it is not closed here:** recovering that subset needs the intermediate
  rewrite-space → authored map the cascade composes but does not retain, plus a
  reverse lookup through it at the diagnostic boundary. That is a
  `verter_compiler` style-cascade source-map capability, an independently
  acceptable outcome in its own right, on a candidate already past every
  mandatory-rescope threshold.
- **Proposed durable owner block:** a new `rev11.style` node owning the
  `verter_compiler` style-cascade source-map surface (retained per-stage
  rewrite-space → authored map). Named by the maintainer, not here.
- **Proposed resolution gate:** no later than plan close.
- **Proposed acceptance ID/test:** `a_refusal_after_a_rewrite_maps_back_to_the_authored_span` —
  the existing `a_refusal_after_a_rewrite_addresses_the_rewritten_space` fixture
  (`.a { color: v-bind(tone); }
}
`, CSS Modules requested) must surface the
  stray `}` at its AUTHORED offset through the public compile boundary, with the
  block-wide anchor retained only where no map exists.
- **Ruling reference:** none yet. This row is the request.
