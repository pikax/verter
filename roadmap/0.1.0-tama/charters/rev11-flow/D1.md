# D1 — Private foundation checkpoint for the sole flow authority

Readiness comes only from trusted implementation-ledger rows. A READY node may start; tooling does not validate commit locators, Git identity, receipts, leases, external state, or runtime admission.

## Independently acceptable outcome

Private foundation for the sole shared flow authority, built behind a private hermetic test boundary. D1 builds the private foundation layer for the sole effective-flow solver as a cutover candidate that is UNREACHABLE from product entry points, sharing the ONE structural graph authority — `FunctionProgramIndex` → `FunctionBodySkeleton` → `FunctionFlowGraph` (flow-completeness contract §1, historical evidence at `0e121f964`) — and the shared relation/inference authority. The current production owner of flow-return resolution remains the **sole shared flow authority**: `ProjectSemanticDispatch` / `execute_function_return_source` (`crates/verter_session/src/project_semantic_dispatch/flow_return.rs`) over the flow substrate in `crates/verter_semantic/src/analysis/flow`, with `crates/verter_session/src/flow_slice_content.rs` as its content-lowering half; D1 replaces nothing and routes around nothing. D1 is a review checkpoint, never independently mergeable or releasable; it lands only inside the atomic D1+D2A+D2B candidate (contract §6; maintainer ruling, 2026-08-29). This charter accepts one authority/foundation boundary; it contains no independently dispatchable subblocks.
