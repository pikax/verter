# D11 — Non-call expression forms in the shallow value pass

Readiness comes only from trusted implementation-ledger rows. A READY node may start; tooling does not validate commit locators, Git identity, receipts, leases, external state, or runtime admission.

## Independently acceptable outcome

The non-call half of the recorded debt RESIDUAL-NON-CALL-ANY-FABRICATION (`crates/verter_session/tests/cases/manifest_data/typeinfo_guard_registry.rs`) is closed: the shallow value pass of the sole shared flow authority no longer answers `_ => Ok(Primitive(Any))` for `JSXElement` / `JSXFragment`, `ClassExpression`, `ImportExpression`, a `super` root, `MetaProperty`, or an optional member read over a non-call base. Each form publishes its typed value through the shared dispatch (the lib `JSX` namespace element type, the class expression's constructor type through the class surface, `Promise<typeof import("m")>` through the module namespace surface, the base member through the heritage surface, `new.target` / `import.meta` through the lib surfaces, `T | undefined` for the optional read) or fails closed with the typed `FlowGap::UnmodeledExpression`; a fabricated `any` never publishes clean and warm, while an authored `x as any` keeps `any`. One independently acceptable outcome; no subblocks.
