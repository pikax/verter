# Tama 0.1.0 roadmap

The program merges current Rev11, the compiler architecture, and the successor expansion into one logical DAG while preserving independent product terminals. A block can start when every transitive DAG ancestor has a trusted implementation-ledger row. External requirements and conflict domains remain agent/maintainer planning instructions; they are not machine locks or readiness validators.

The graph deliberately has no all-products join. L4 closes Rev11; BR0 is an ordinary predecessor for successor work; each other product owns its own terminal. Sizing, review, integration, and the trusted ledger workflow are centralized in `contracts/`, keeping packets and charters compact.
