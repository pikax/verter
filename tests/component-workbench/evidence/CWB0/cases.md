new test suite, receipt or claim that downstream features execute today.

the named product nodes retain their own tests and existing test lanes.

## Verification applicability

CWB0 changes only the contract and this case table. No query state, map,
cache, runtime, public DTO, dependency pin or code behavior is changed.
Consequently there is no executable TDD delta or new freshness validator to
run, and no runtime/incremental/performance result claimed. Repository cheap
format/whitespace checks apply to the authored documents; actual commands,
platform, candidate identity and outcomes belong to this turn's report, not a
committed transcript. The workflow runs the canonical gate on the published
head. Public examples and exact runtime/version receipts remain obligations
of the named implementation producers and CWB9, not placeholders accepted as
finished products by this decision.
